## 断法只有四句

```
① 定调一句    看格名或最反常处
② 逐象直说    一象一事，可并列三五条，互不推导
③ 结果一句    几年、几时、死生
④ 办法一句    象指哪改哪
```

## 两种排盘

```bash
# 全课总览
python3 -c "from brief import brief_text; print(brief_text('壬','午','丑','卯',month_zhi='子'))"
# 按类神摆象（推荐）
python3 -c "from brief import lei_brief; print(lei_brief('壬','午','丑','卯','午',month_zhi='子'))"
```
