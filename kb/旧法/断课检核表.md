# 断课检核表（每次开课照此走一遍）

## 〇 开局三问
1. **所问何事**？（定事类，取出类神——不看这一步，后面全白做）
2. **谁问的**？（本命、行年、性别；主客表定日＝谁、支＝谁）
3. **何时问的**？（昼夜定贵人；月将定天盘；旬空定虚实）

## 一 排盘核对（四查）
- [ ] 四柱对不对（年月日时干支）
- [ ] 月将对不对（中气换将）
- [ ] 旬空对不对（日干支定旬）
- [ ] 贵人昼夜与顺逆对不对（景祐表；临地盘亥至辰顺、巳至戌逆）

## 二 六层定位（不可越级）
| 层 | 查什么 | 出什么 |
|---|---|---|
| 一 五行 | 三传与日干谁克谁、旺相休囚死 | **方向**（吉/凶/耗/受制） |
| 二 干支 | 干上＝我、支上＝彼、干害支生 | **谁** |
| 三 长生 | 墓、绝、死、帝旺 | **生死成败** |
| 四 天将 | 作人还是作事，按位取 | **什么事** |
| 五 神煞 | 是否临干支年命，是吉神还是凶神 | **轻重** |
| 六 类象 | 支象定物、将临宫定事态 | **具体内容** |

## 三 硬判据（先查这七条）
1. [ ] **末传克日**？→ 事凶、受制、必止（甲级 100%）
2. [ ] **末传空/入墓**？→ 无终 / 事止
3. [ ] **死门**（三传死墓绝＋无救）？→ 主死
4. [ ] **禄空 / 官空 / 常空**？→ 位不实、失职
5. [ ] **天目加支 / 魁罡蛇虎临日辰**？→ 伏尸
6. [ ] **三合局与化气**？→ 事势与转化
7. [ ] **六阴俱备 / 极阴**？→ 衰败（丙级，仅提示）

## 三·五 器物相加（查表）
三传两两成对时，先查 `pair.py` 的 **29 组**（实测 63%）：
- 辰加亥＝堤岸与水 → 水边、河堤
- 巳加亥＝灶厕不便
- 子加亥＝孙字 → 添孙
- 巳加酉＝炉灶与金 → 灶下、灰中
- 辰加戌＝两墓相冲 → 旧冢、伏尸
- 亥加申＝池与堕水
- 寅加亥＝闭口
**有对即报，无对不凑。**

## 四 类象取证（人→物→事→处→变）
- 人＝六亲对该支
- 物＝该支在本事类的类神义（查类象事类表）
- 事＝所乘之将（按位取人还是取事）＋所临宫定名
- 处＝所临地盘之支
- 变＝所披之煞

## 五 空亡两分
- 空的是**凶神**（白虎、玄武、劫煞）→ **减凶**
- 空的是**吉神**（禄、官、长生、贵人、太常）→ **吉化为虚、转凶**
- 煞虽空，仍主「有此事而不重」，**不可断无事**

## 六 应期（新法）
1. 三传之支值日：初传最速、中传次之、末传少应
2. 空亡待填实（出旬值支之日）
3. 入墓待冲开
4. 被冲应冲日、被合应合日
5. 月建发用应本月
6. 数法只作参考
- **已废**：季神法（孟辰仲未季戌），实测 15%

## 七 分寸三条（防过度）
1. 一象只说一事，不把象推成数事
2. 「可」与「必」分开；冲开墓只主「可动」
3. 一课最多三链，第一条必是所问

## 八 表达格式
```
初看：日上与初传之象（最易骗人处）
中途：三传生克流转
究竟：末传（归计）定结局
必答：何人、何事、何时、何果
```

### 三·五·二 三传不成对时的替代路（查 place.py）
| 层 | 查什么 | 例 |
|---|---|---|
| 处所 | 类神所临之**地盘支** | 戌临申 → 抽屉、走廊 |
| 环境 | 类神所乘之**将** | 乘朱雀 → 纸本文书堆 |
| 合成 | 处所＋环境 | 抽屉＋纸本文书 → **文件柜** |

实证：毕业证案，中传戌临申乘朱雀 → 断「文件柜」，实际就在办公室文件柜。
