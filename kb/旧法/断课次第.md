# 断课次第（照邵彦和的路子）

## 一 先看邵彦和怎么开口

| 案 | 第一句 | 性质 |
|---|---|---|
| 张九翁占宅 | 「干支皆受上神来生，**利宅不利人**」 | **定主客** |
| 某占宅 | 「此课**支来就干为干所制**，名曰赘婿」 | **定格局** |
| 某占婚 | 「此课乃**妻为主**，日去加辰」 | **定主客** |
| 童保仪 | 「此课**六阴相继，更无阳神**」 | **定课体** |
| 王德卿 | 「此课**财禄极稳**，但自有膀胱气」 | **先定调，再说病** |
| 某占宅 | 「此课**德丧神消，人亡家破**。何以言之？」 | **先下断，后解释** |

**规律：第一句永远是「总调」——不是象，是势。**

## 二 次第（照书上的实际顺序）

```
一 定主客    干为我？支为彼？谁为主？
二 定格局    课体、成局否、六阴六阳、空否
三 定调      一句话：此课是什么势（利宅不利人／财禄极稳／德丧神消）
四 抓主象    最反常处
五 展开      象的诸面
六 串联      象成链
七 落事      何人何事何时何果
八 应期      从断语长出
```

**关键差别**：**先定调，后抓象。**
不是「看到一堆象再凑事」，是「先看出这课是什么势，再找象去说清它」。

## 三 定主客之法
| 问 | 主 | 客 |
|---|---|---|
| 占自己事 | 干 | 支 |
| 占宅 | 支为宅 | 干为人 |
| 占他人 | 支 | 干 |
| 占婚（男占） | 干为我 | 支为妻 |
| 占讼 | 干为我 | 支为彼 |
| 占买卖 | 干为我 | 支为货 |

**主客一定，象才有归属。** 不定主客，象不知说谁。

## 四 定调之法（一句话定势）
从三处取：
1. **日上与支上的关系**（生我／我生／克我／我克／比）
2. **三传的整体走向**（进／退／成局／空／墓）
3. **课体**（六阴、赘婿、乱首、顾祖、返吟…）

**例**：
- 干支皆受上神生 → 「利宅不利人」
- 支来就干为干所制 → 「赘婿，无正居」
- 六阴相继无阳神 → 「阴长阳消，极矣」
- 财禄旺而支有鬼 → 「财禄极稳，但自有某病」

## 五 邵彦和的三种断法

### 一 先断后释（最常用）
> 「此课**德丧神消，人亡家破**。何以言之？……盖壬德在亥，亥为闭口，无德可言，是谓德丧。」

**先一句断死，再逐条解释。** 解释是给读者看的，断是给自己看的。

### 二 边断边释
> 「干支皆受上神来生，**利宅不利人**。干上发用归传支，末传亥脱今日之干而生今日之支，因充役费用……」

**断一句，释一句。**

### 三 只释不断（少见）
> 「凡传用，若干支阴阳已先据其位，只以不备推测，不可重复取用。」

**讲法不讲断。**

## 六 取舍：哪些象不说
邵彦和从不说全部象。他的取舍标准：

1. **能成链的说**（象要能串起来）
2. **能落到物的说**（树、门、灯、灶）
3. **能应期的说**（某年某事）
4. **不成链的、落不到物的，一律不说**
5. **「不发用，不可乱断」**（沈注）——象在课中但不当权，不断

**反过来说**：断语里出现的每一个象，都必须能在课中指出来。
指不出来的，就是编的。

## 七 与现流程的差别
| 现流程 | 应为 |
|---|---|
| 一上来抓主象 | **先定主客、定格局、定调**，再抓主象 |
| 12 步平铺 | **八步，前四步都是"定"** |
| 象在先 | **势在先，象在后** |
| 没有取舍标准 | **能成链、能落物、能应期者说，余者不说** |

## 八 定调四式（邵彦和开口的四种句式）

### 式一 「干支X，利A不利B」
> 「**干支皆受上神来生，利宅不利人**。」

**用于**：日上与支上的生克不同向。
**取法**：看日上、支上各是生我／我生／克我／我克／比，两者相反即用此式。

### 式二 「此课X为Y所制，名曰Z」
> 「**此课支来就干为干所制，名曰赘婿**。」
> 「此课日去加辰，夫去脱妻……」

**用于**：有明显的主客倒置或课体成格。
**取法**：看支加干、干加支，谁制谁；再看课体名。

### 式三 「此课X，更无Y」
> 「**此课六阴相继，更无阳神**。」
> 「此课德丧神消，人亡家破。」

**用于**：课体偏枯，一边倒。
**取法**：看六阴六阳、全空全实、纯生纯克。

### 式四 「此课X极稳，但自有Y」
> 「**此课财禄极稳，但自有膀胱气及阴肿水气之扰**。」
> 「此课人盛宅狭，人与宅替。」

**用于**：一面大好，另一面有暗病。
**取法**：先取最旺之一面（财禄、人丁、宅气），再取暗中之病（本命上神、支上神、末传）。

**四式的共同点**：**都是「一面＋另一面」，不是单说吉或单说凶。**

## 九 三程纵贯（问事课也要分初、中、末）

邵彦和断事，几乎都走一条时间线：

> 「**初**传脱气，**中**传入墓，**末**传空亡 → 先难、中滞、终无」

| 程 | 看什么 | 主 |
|---|---|---|
| **初程** | 初传＋日上 | 事之起（当下、近况） |
| **中程** | 中传＋支上 | 事之中（转折、变化） |
| **末程** | 末传＋本命／行年 | 事之终（结局、归着） |

**三程各自要答一句**：
- 初：这事怎么起的？
- 中：中间会怎样变？
- 末：最后落到哪里？

**注意**：三程不等于三限。三限是「少年／中年／老年」（终身课用），三程是「起／中／终」（问事课用）。**同一套三传，两种读法。**

## 十 多重死象检测（为什么邵敢说死）

> **邵彦和断死，必有多重象义同指。他只说结论，不说全部证据。**

### 死象清单（同一课中出现几条）
| # | 死象 | 出处 |
|---|---|---|
| 1 | **末传克日** | 实测 100% |
| 2 | **末传入墓** | 事止 |
| 3 | **末传空亡** | 无终 |
| 4 | **传归死墓** | 丙午日案 |
| 5 | **上下俱脱** | 张逸士案 |
| 6 | **四课俱下贼（绝阴）** | 庚辰日案 |
| 7 | **本命上神临死墓绝胎养** | 寿夭法 |
| 8 | **日干在月令死绝** | — |
| 9 | **死神带虎克日＋空亡（黄泉鬼）** | 邵氏通则 |
| 10 | **壬日行丑寅卯进脱＋支上绝神** | 邵氏通则 |
| 11 | **行年入三传之支** | 与病同途 |
| 12 | **干支各乘墓** | 人昏宅暗 |

### 判法
| 死象数 | 断 |
|---|---|
| **≥3 条** | **可断死**，并给出年／月 |
| **2 条** | 断「危」，不给死期 |
| **1 条** | 只作「关口」 |
| **0 条** | 不断死 |

**关键**：这 12 条**来源各不相同**（末传、四课、本命、月令、行年、神煞），所以是「异源同指」，不是同一象的多面。

### 救神（有则可延，须扣减）
| 救 | 效力 |
|---|---|
| 行年退在传后 | 强 |
| 时令旺身 | 强 |
| 本命上神长生 | 中 |
| 贵德临身 | 中 |
| 暗贵人 | 弱 |
| 制鬼之神（良医） | 中 |

### 判法：三问过滤（不是加减）

> **加减法是死的，救是活的。**

```
一问：此凶落空否？   → 空则不发（凶本身不成立）
二问：有制之者否？   → 有制则转（转成别的事）
三问：能改否？       → 能改则免（人事上避开）
三者俱无，方断死
```

| 情形 | 断 |
|---|---|
| 死象≥3 且 三问俱无解 | **可断死**，并给年月 |
| 死象≥3 且有解 | **危而可救** |
| 死象=2 | 危，不给死期 |
| 死象=1 | 只作关口 |

**为什么不是加减**：救不是「抵消」死象，是
- **落空** → 该凶根本没发生
- **有制** → 转成别的事（不死而破财）
- **能改** → 人事上避开（迁居、戒酒）

**所以「多重死象犹可回生」，是因为那些死象有的没落地。**

### 三条铁律（实测得出）
1. **上下俱脱者，月令旺相不能救**——脱从两处泄，月令补不上（张逸士案）
2. **月令判死之正法**：克我者当令→我死（`KE[月令]==日干`）；我克者当令→我囚
3. **同一死象数，救力定生死**：张逸士 4 死象 0 救→死；叶解元 4 死象 1.5 救→不死

### 实证三案
| 案 | 死象 | 救力 | 判 | 书上 |
|---|---|---|---|---|
| 张逸士 | 4 | 0 | 可断死 | **死**（二十八日）✓ |
| 叶解元 | 4 | 1.5 | 危而可救 | **不死**（今冬得子）✓ |
| 某占病 | 3 | 0 | 可断死 | **死**（传归死墓）✓ |

## 十一 三处修正（据三案实测）

### 修正一：定调先取格名，再取句式
**支加干者，先看课体格名，再定调。**

| 象 | 格名 | 含义 |
|---|---|---|
| 支加干被干制 | **赘婿** | 入赘、无正居、寄人篱下 |
| 支加干克干 | **上门乱首** | 下犯上、被欺压 |
| 支加干生干 | **上门相惠** | 送上门的好处 |
| 三传回本家 | **顾祖** | 去了又回 |

**格名一取，整课性质即定。** 例：叶助教案，书上定调「支来就干为干所制，**名曰赘婿**」——赘婿即无正居，故「六年家破屋拆，遂成墓地」。

子 agent 只取句式①「利宅不利人」，**漏了格名，故断不出「屋不存立」**。

### 修正二：应期先定年，再落月日
**次序：数法定年 → 支值月日 → 填实冲开。**

| 案 | 数法 | 年 |
|---|---|---|
| 叶助教 | 卯数六 | **六年** |
| 童保仪 | 宅上卯、末传酉俱六数 | **六年**（四年先败） |
| 叶七秀才 | 亥四子九＝十三 | **十三年** |

**只给月日＝只断小应期。** 须先算年数，再往下落。

### 修正三：断完主事，再问「之后引出什么」
邵彦和断课不停在「成／败」，要断到**后续之事**：

| 案 | 主事 | 后续 |
|---|---|---|
| 叶助教 | 六年家破屋拆 | **必葬尊长在内** |
| 童保仪 | 四年败、六年败尽 | 拆屋卖、移出店屋住 |
| 童秀才 | 官断不明、换衙门 | **彼必葬老阴人于内** |

**断法**：主事断完，看末传归处与墓库——
- 末传入墓 → 后有葬埋、收殓、封存之事
- 末传归支 → 事归彼方，后有交割
- 末传空 → 后无着落

## 十二 定调三层（据三案实测修正）

**定调不是一句话，是三层：**

```
一 定主    此课以谁为主？（妻／夫／宅／人／彼／我）
二 取格    取与所问最切之格名（非最显眼者）
三 定调    主＋格 → 一句话
```

### 第一层 定主（最易漏）
| 案 | 书上定主 | 据 |
|---|---|---|
| 邵三翁 | **乃妻为主** | 辛以卯为妻，上见天后；干又就支，反致勾留 |
| 叶助教 | 宅为主（赘婿） | 支来就干 |
| 童得松 | 身命为主 | 身命临亥 |

**定主之法**：看哪一方**临日干**、**乘吉将**、**是所问之事的核心**。
- 占宅而宅加干 → 宅为主
- 占婚而妻爻临干乘天后 → 妻为主

**主一定，后面的关系（谁克谁、谁脱谁）才有意义。**

### 第二层 取格（取最切者）
**一课常有数格，取与所问最切者，不取最显眼者。**

| 案 | 有哪几个格 | 书上取 |
|---|---|---|
| 童得松 | 返吟、励德、斩关 | **德丧神消**（非返吟） |
| 邵三翁 | 重审、斩关、励德、不备、斫轮、乱首 | **妻为主**（非乱首） |
| 叶助教 | 重审、励德、不备、斫轮、赘婿 | **赘婿**（取赘婿） |

**取法**：问什么，取什么格。
- 问宅 → 取与宅相关之格（赘婿、乱首、六阴）
- 问婚 → 取与婚相关之格（芜淫、佚女、赘婿）
- 问官 → 取与官相关之格（无禄、天狱、官爵）
- 问讼 → 取与讼相关之格（天网、龙战、乱首）

### 第三层 定调（主＋格→一句话）
**句式：「此课【主】为【格】，故【断】」**

| 案 | 定调 |
|---|---|
| 邵三翁 | 此课**乃妻为主**，日去加辰，**夫去脱妻**，妻为长夫反为少 |
| 叶助教 | 此课**支来就干为干所制，名曰赘婿** |
| 童得松 | 此课**德丧神消，人亡家破** |

## 十三 数法定年之后，还要分年
**先给总数，再给具体某年发生何事。**

| 案 | 总数 | 分年 |
|---|---|---|
| 邵三翁 | **九年相守** | **第八年**因作生地，与兄弟不足；**目下**主丧妻 |
| 叶助教 | **六年**家破屋拆 | **六年之前**四分五裂 |
| 童保仪 | **六年败尽** | **第四年**拆四边屋卖 |

**分年之法**：看数法所出之支，其前后各支所主之事。
例：邵三翁「戌加巳，上五下四，共九数」→ 九年；第八年为酉，酉冲卯（妻），故第八年妻事。

## 十四 三条要点（重新排序，此为纲）

> **不可舍本逐末。** 定调句式、格名取法，都是末。本是三条：

### 一 核心问题不能算错
**问什么，那个答案必须对。** 其余都是次要。

| 问 | 核心答案是什么 |
|---|---|
| 占宅 | 宅能不能住、会不会败、几年败 |
| 占病 | 什么病、死不死、几时 |
| 占讼 | 谁胜谁负、断得明不明 |
| 求财 | 得不得、几时得 |
| 失物 | 找不找得回、在哪 |
| 婚 | 成不成、谁不愿 |
| 前程 | 成不成、几时、做到什么位 |

**若核心答案错，其余全对也无用。**

### 二 尽量挖出多的事（不止答所问）
**邵彦和从不只答一句。** 例：

> 叶助教占宅，问的是宅。书断：宅败（核心）＋**必葬尊长在内**＋**还俗僧入挠、门户分张**＋**当年又死一男一女**＋**经官分家产**。

> 童保仪占宅，问的是宅。书断：宅败（核心）＋**婢殒命于厕**＋**宅前大树枯朽**＋**一子患腹气**＋**后阁养猪**＋**兄弟分出**。

**挖法**：
1. **逐传挖**：初传主何事、中传主何事、末传主何事
2. **逐神挖**：本命、行年、日上、支上、各传所乘之将，各主一事
3. **逐宫挖**（终身课）：十二宫各主一事
4. **器物相加挖**：每一对成象即一事
5. **看「不该有的东西」**：空亡处、破碎处、墓库处——那里藏着未发之事

**分寸**：挖出来的每一条，都须能在课中指出来的象。**指不出来就是编。**

### 三 给解决办法（不只断吉凶）
**邵彦和断完凶，必给一条活路。**

| 案 | 凶 | 办法 |
|---|---|---|
| 童得松 | 德丧神消，人亡家破 | **迁店居住，其户遂宁，祸亦解** |
| 姜子 | 贪色，不即日为泉下人 | **改干亥山向，决宅水东流，戒酒色，犹可延** |
| 徐秀才 | 防瘫痪 | **决坤申水、通艮寅风，可免此灾** |
| 叶七秀才 | 十三年疝气亡 | （未给，属不可改） |
| 邵三翁 | 九年相守，第八年作生地不利 | **不动土、不争财则减** |

**给法五条**：
| 类 | 办法 |
|---|---|
| **迁** | 迁居、迁店、换址、换行 |
| **改** | 改门向、改坟山向、改水道、改通风 |
| **戒** | 戒酒色、戒争、戒贪、戒动土 |
| **避** | 避某方、避某人、避某时 |
| **求** | 求贵人、求医、求调解、求文书 |

**断法**：见凶之后，必查——
- 有没有「可迁」之象（驿马、斩关、游子）
- 有没有「可改」之象（天罡指方、闭口待通）
- 有没有「可戒」之象（酒色之神、争斗之神）
- 有没有「可避」之象（凶神所在之方）
- 有没有「可求」之象（贵人、天医、制鬼之神）

**有一条，就给一条活路。**

### 三者的次序
```
一 先答核心问题（必对）
二 再挖相关之事（尽量多）
三 最后给办法（有凶必给）
```

**不可颠倒。** 格名、句式、取象，全是为这三条服务的。

## 十五 最深一层：六壬是「说出课里已有的东西」（非推理）

### 一 邵彦和开口先说「来意」
**求财案原文**：
> 「邵先生曰：**汝欲妻家去取财，未得又欲问令岳父借之**。占人笑曰：**果是**。」

**在对方说出问题之前，先说他在干什么、下一步想干什么。**

**这不是专门技术，是每一课的第一步。**

| 案 | 先说的「境」 |
|---|---|
| 求财 | 汝欲妻家去取财，未得又欲问岳父借 |
| 占婚 | 何必有媒？私情久已通矣；其家房合广阔，东西皆有小门 |
| 叶助教 | （先说宅的样子与宅败之势） |
| 童保仪 | 此课六阴相继，更无阳神 |

**为什么先说这个**：
1. **取信**——说对了，后面的话才有人听
2. **定类神**——日上神即此人所处之境，境即事，事即类神
3. **象才归位**——知道他在干什么，才知道该看哪些象

### 二 「给办法」不是建议，是指出课里那条通着的路
**求财案的「再借必得」**：
- 寅（子孙）生午（财）→ 他想借，路在课里
- **中传申＝长生成尊长，乘青龙＝财类神 → 这条路通**

**不是我说「你去借」，是课里那条路本来就通。**

| 案 | 办法 | 课里的依据 |
|---|---|---|
| 求财 | 问岳父借 | 中传申：长生＋尊长＋青龙（财类神） |
| 童得松 | 迁店居住，祸解 | 反吟、斩关 → 来去不定、不能安居 |
| 姜子 | 改亥山向、决水东流、戒酒色 | 宅上亥（水）→ 水停在宅上，故导之 |
| 徐秀才 | 决坤申水、通艮寅风 | 甲寅加癸亥真闭口 → 闭则通之 |

**办法也在象里。** 课里哪条路通，就说哪条；没有通的路，就说「无解」。

### 三 全流程都是「看见」，没有「推理」
| 环节 | 看什么 | 说什么 |
|---|---|---|
| **断来意** | 日上神（所处之境） | 你在干什么、想什么 |
| 断现状 | 相关之象 | 你身边是什么样子 |
| 断结果 | 类神归处、末传 | 最后落到哪 |
| **给办法** | 课里通着的那条路 | 该走哪条 |

**「午为马加申道路之上」——看见的，不是推的。**
**「婢子为脚」——看见的。**
**「其家房合广阔，东西皆有小门」——看见的。**

### 四 由此改流程
**原流程从「问什么」直接跳到「类神是什么」，这一步靠猜。**

**应改为**：
```
〇 观境断来意   看日上神 → 先说此人所处之境、所问何事
一 定类神       由境定类神（境即事，事即类神）
二 摆象         类神的象（不在传＝事隐；上神空＝虚）
三 说结果       类神归处、末传
四 挖相关       其余可验之象
五 指路         课里哪条通
六 应期
```

**先说「境」，再说「事」，再说「果」，最后指「路」。**
