# 象学（六壬的本体）

## 一 断＝象，析＝理

《断案》每一案都有两段：**【断】** 和 **【析】**。

| 段 | 用什么 | 例 |
|---|---|---|
| **【断】** | **象**（画面） | 「午为马加申道路之上，**正行也**，被人骑去矣」 |
| **【析】** | **理**（五行、长生、数） | 「一土生二金，是退子也」；「卯数六」 |

**【断】里几乎没有五行生克。「析」里才全是。**

**故：断课靠摆象，理只用来解释象、验象、定应期。**

## 二 邵彦和是「描述一幅画」，不是「回答一个问题」

**占婚案（最典型）**：

书上【断】：
> 「此课占婚，**何必有媒**？**私情久已通矣**。其家房合广阔，东西皆有小门，**因婢子为脚**，遂与人通。今所议之人，亦与奸淫，**血支在卯，必非女身**，主**暗有退子**。」

**通篇没有一句「成」或「不成」。** 但读者一看就明白：**既成事实，婚当然成。**

**结论在画里，不在话里。**

## 三 「回答一个问题」会怎样

子 agent 的做法：
> 「六合临酉而旬空——**有名无实**，媒妁虚设」→ 理 → **不成**

**推得通，但错了。**

因为它把「六合空」解成「无实」，用理去推。而书上根本不看六合空与否，它看的是「**酉为婢，六合加之**」——**婢子做媒**这幅画。

## 四 摆象的三条规矩

### 一 象要成画（有物、有位、有动作）
- ✗ 「卯＝官鬼，己土死于卯」——这是理
- ✓ 「卯加酉，卯为门，酉为私门，门来加户」——这是画

### 二 象要带将（将定其事）
- 支只给材料，**将才说是什么事**
- 「酉」（婢）＋「六合」（和合、媒）＝**婢子做媒**
- 「午」（马）＋「申」（道路）＝**马在路上走**

### 三 象要串成一幅画（不是罗列）
```
婢（酉）＋ 合（媒）＋ 私门（卯酉）＋ 门加户（卯酉相加）
        ↓
「房舍广阔，东西有小门，婢子为脚，与人私通」
```

**一串象，一幅画，一件事。**

## 五 象的次序（摆象时按这个顺序）

```
一 类神    所问之事的类神是谁（婚：六合/妻财；马：午；财：财爻）
二 类神在哪  其一：地盘某支，其上神为何（现在何处）
             其二：天盘所临之地（往哪去）
三 类神乘何将 定何事
四 与谁相加   器物对、邻支、对冲
五 年命所关   本命上神、行年上神、男女互乘、命入何传
六 空墓处     空亡、入墓、破碎之处，藏着什么未发之事
```

## 六 理的三处用处（只此三处）

1. **验象**：象说「成」，理看有无大凶克日，验其是否被破
2. **定应期**：数法（太玄数、几见、支数）
3. **定轻重**：旺衰决定「重不重」

**理不用来「推结论」，只用来「验象」和「定时」。**

## 七 一条实证对照

| | 子 agent（理） | 书上（象） |
|---|---|---|
| 失马 | 玄武不入传→非盗；午上神辰→在厩中受惊；断**寻得回** | **午（马）作天盘神，临地盘申（道路）→ 在路上走 → 被人骑去** |
| 占婚 | 六合空→有名无实；官鬼旺克身→耗男方；断**不成** | **婢子为脚、私情已通、非女身 → 既成事实 → 必成** |

**同样的盘，理推出 A，象推出 B。象赢。**

## 八 一句话
**理可以推出无数种结论，象只有一个。**
