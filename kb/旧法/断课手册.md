**昼夜必问**：同一课，昼占夜占结论可相反。

## 一 四套全断
| 套 | 出什么 | 用途 |
|---|---|---|
| 十断 | 十类事各一方向 | 定「问的是哪一类」 |
| 器物相加 | 三传成对的具体事件 | 定「是什么事」 |
| 类神临处 | 方位、处所、环境 | 定「在哪里」 |
| 旺衰成败 | 每传六亲与长生位 | 定「成不成」 |

## 二 六层（不可越级）
五行定方向 → 干支定人 → 长生定生死 → 天将定事 → 神煞定轻重 → 类象定内容

## 三 十条硬判据
1. 末传克日 → 凶（100%）
2. 末传入墓／空 → 事止／无终
3. 日上神空 → 我无意、我不实
4. 支上空 → 事体虚、宅基未定
5. 类神临沐浴 → 事不成形
6. 类神空亡且作鬼 → 事黄
7. 财与财库俱破碎 → 求财不成
8. 闭口临支 → 门不开
9. 末传贵人闭口 → 对方拒绝
10. 干支各乘墓 → 人昏宅暗

## 四 十类事判据（详批注总表）
### 天时
天罡加亥水运乎上＝雨｜天罡指阳＝晴｜水神空＝阴而不雨｜返吟＝问晴得雨
### 疾病
支象定脏腑｜**新病愈、久病凶**｜制鬼之神＝良医｜上下俱脱＝吐泻虚损
### 胎产
胎神空＝未孕｜上克下男、地克天女｜润下易产｜神坐长生宜胎不宜产
### 婚姻
日上神空我无意｜本命空我不愿｜支上空对方无意｜合而不合｜桃花咸池不成乃妙
### 求财
财空难得｜财库俱破不成｜二传子孙不求自至｜财化为鬼因财致祸｜小财不去大财不来
### 仕宦
禄空位不实｜官煞旺不利｜三传遁生当有荐｜贵而无位｜遍地贵人＝多差使
### 家宅
支上空宅基未定｜支为日墓有旧冢｜破碎临宅屋损｜白虎生支生白蚁｜干受支克＝人衰宅旺
### 行人
天罡加孟未动、加仲在途、加季立至｜驿马入宅即至
### 出行
马空难行｜三传回环去了又回｜陆路利昼水路利夜｜关格路阻
### 兵
权不自己出兵不安｜敌有救兵不可追｜勾陈相生不战相克战
### 埋葬
墓神逢空反吉｜丑上午穿防兽穴

## 五 空亡两分
- 空凶神（白虎、玄武、劫煞）→ 减凶
- 空吉神（禄、官、长生、贵人、太常）→ 转凶
- 煞虽空，仍主「有此事而不重」

## 六 应期
1. 三传之支＋日支，初传最速、末传少应
2. 空亡待填实、入墓待冲开、闭口待冲开
3. 旺则倍之、衰则折半、空亡减半、可增半
4. 出旬方应

## 七 装配（零件→结论）
| 组合 | 结论 |
|---|---|
| 官星死绝＋长生空＋末传天空 | 贵而无位 |
| 日上空＋三传吉 | 到好处不中事 |
| 初传寅前引、末传子后从，用神空 | 虚声无实 |
| 财合鬼 | 财不为我用，反成祸 |
| 三传不出四课 | 吉凶皆不成，止宜守旧 |
| 三传递生而所生空 | 动则投脱，不如守 |
| 初蛇末虎 | 变为悔 |
| 贵德临身 | 可改凶为吉 |

## 八 分寸
1. 一象一事
2. 「可」与「必」分开
3. 最多三链，第一条必是所问
4. **须落到：处所／方位／人物／年月／数量／动作，六者之一**
5. 只到「吉凶」＝未断出

## 九 忌
- 见凶不骤断死（须日辰亦凶）
- 见吉不断必成（须看承载）
- 链不过三节
- 不可先算数再凑事
- 排盘不符先查 OCR／输入

## 十 表达

究竟：末传定结局
