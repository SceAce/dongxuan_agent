# 七层综合断法（解决「只用一层就下断」）

## 病灶
断终身课时，只用了「身命占」那两条（命上神、应期），
**其余五层全漏**：六亲、方位、将象、类象、数法。

书上一条断语，往往用了三四层。例：
> 「丑土生辛金，故为母。辛以寅为妻，故因妻起家。寅艮方，丑加之，故艮山坟地。
> 金绝于寅，故主妻死。……亥为肾，玄武主疝气，金死于子，故十三年疝气而亡。」

**十句话，七层技法。** 少一层就断不出。

## 七层各答什么

| 层 | 回答 | 输出的东西 |
|---|---|---|
| **一 五行** | 生克方向 | 此传对我是克、生、脱、比 |
| **二 六亲** | 这是谁 | 父母（长辈）／财（妻、钱）／子孙（子女、福德）／官（职、病、讼）／兄弟（同辈） |
| **三 长生** | 生死与阶段 | 长生／临官／帝旺／衰／病／死／墓／绝／胎／养 |
| **四 将象** | 什么事 | 白虎＝血光、道路；玄武＝暗昧、盗、疝；天后＝妇人、水；太阴＝阴私、藏 |
| **五 方位** | 在哪 | 支之卦位 ＋ 所临地盘之卦位 |
| **六 类象** | 具体何物 | 亥子＝肾，丑未＝脾腹，寅卯＝肝胆，巳午＝心，申酉＝肺 |
| **七 数法** | 几年几人几处 | 太玄数相加／相乘／折半／增半 |

## 用法：逐层过，缺层标「无据」

```python
from layers import seven
for k, v in seven(r, 日干, 日支).items(): print(k, v)
```

**规矩**：
1. **七层都要过一遍**，不许跳过
2. 某层无内容，**明写「此层无据」**，不许默默略过
3. 下断语时，**须「异源同指」**——不同的象（不是同一象的不同面）指向同一结论，方为定论
4. **层与层要串联**，不许各说各的

## 串法（举例）

**例：叶七秀才疝气死**
```
第 2 层（六亲）→ 辛以寅为妻，寅是财
第 3 层（长生）→ 辛金绝于寅
                    ↓
              「妻死」── 两层合一
第 6 层（类象）→ 亥为肾
第 4 层（将象）→ 玄武主疝气
第 3 层（长生）→ 辛金死于子（子在中传）
第 7 层（数法）→ 亥四子九＝十三
                    ↓
        「十三年后疝气而亡」── 四层合一
```

**一条断语用了四层。** 这就是「综合取象」。

## 反向检查：断完之后回头查

断完一课，问自己三句：
1. **七层里我用了几层？**（少于三层，多半断浅了）
2. **有没有哪层明明有内容却没用？**（漏层即漏事）
3. **各层的结论是不是指向同一处？**（相悖则须辨哪层更硬）

## 层的硬度（相悖时取谁）
| 硬 | 十层铁律：末传 > 类神 > 课体 |
|---|---|
| 次 | 三证合一（病象＋死地＋年数）> 单证 |
| 软 | 单象、单数、单将 |

**两说相悖，取硬者；软者降为「或有」。**
