## 一 排盘与次第

```python
from brief import brief_text
print(brief_text('日干','日支','月将','时支', month_zhi='月建', age=岁, birth_gz='生年干支'))
```

**禁编三条（先记）**：①三级证据：**甲＝盘上事实**（支/将/临/空/墓/几见，直读必准）｜**乙＝象**（甲级组合，须标象名）｜**丙＝由象推事**（须两象同指、标「或」，每课≤3句）
②推理链**不过二步**（午加申→在路→被骑走 是1步，可说；日上酉空→因酒食疏忽 是3步，须标「或」）
③**说不出象的不许说**——每句回问「能指回哪个支、哪个将、哪一处？」指不回就删。
**禁说**：具体场景细节、人的心理动机、无三证的具体未来事件。
**宁可少说，不可乱说。**

**象学**：**断＝象，析＝理。**
【断】全是画面（「午为马加申道路之上，正行也」），【析】才用五行长生数。
**用理推结论必错**——见六合空推「有名无实」，推得通但错。
**摆象六序**：类神是谁 → 类神在哪（地盘上神＝现在何处／作天盘神所临＝往哪去）→ 乘何将 → 与谁相加 → 年命所关（含男女互乘）→ 空墓处藏着什么

**三条要点（纲）**：
1. **核心问题不能算错**——问什么那个答案必须对
2. **尽量挖出多的事**——逐传/逐神/器物/空亡墓库处，不止答所问
3. **有凶必给办法**——迁（迁居换行）｜改（改向改水道）｜戒（戒酒色争贪）｜避（避方避人）｜求（求贵人医调解）

**断课次第**：
1. **定主客**——干为我？支为彼？（占宅：支为宅、干为人）
2. **定格局（取格名＝拿钥匙）**——先九宗门（元首/知一/涉害/遥克/昴星/别责/伏吟/返吟/八专），
   再三合局（稼穑·自微至著｜曲直·福善祸淫｜从革·伤情改革｜炎上·气焰上进｜润下·恩泽下施），
   再特殊格（**赘婿**·支加干被克→屈身依人不能自立｜**乱首**·日加辰被克→悖逆｜**无禄**·四上克下→上骄下弱｜
   **绝嗣**·四下克上→下逆上伤｜**龙战**·卯酉发用→更革灾祸｜**芜淫**·互克干支→夫妻异心｜
   **三交**·四仲全见→藏匿阴私｜**斩关**·罡魁加干→奔波｜**游子**·四季＋丁马→碌碌｜
   **天狱**·用囚死＋罡加日本→官非｜**天网**·时支并克干→词讼｜**玄胎**·四孟在传→隐匿｜**厉德**·贵人当卯酉→摇动），
   再六阴（丑亥酉卯尽见→阴长阳消衰败）
3. **定调（三层）**——①**定主**：此课以谁为主？（占宅宅加干则宅为主；占婚妻爻临干乘天后则妻为主）②**取格**：取与所问最切之格，非最显眼者 ③**定调**：主＋格→一句话「此课【主】为【格】，故【断】」
   **格名**：支加干被制＝赘婿（无正居）｜支加干克干＝上门乱首｜支加干生干＝上门相惠｜三传回本家＝顾祖
   **句式**：①「干支X，利A不利B」②「X为Y所制，名曰Z」③「此课X，更无Y」④「X极稳，但自有Y」
4. **抓主象**——最反常处（几见／俱下贼／上下俱脱／传归死墓）
5. **取象**——象＝名义＋体性＋位势＋生成
6. **串联**——象成链
7. **三程**——初（起）／中（变）／末（落）
8. **见凶三问**——落空否？（不发）有制否？（转）能改否？（免）三者俱无方断死
9. **落事**——何人何事何时何果
10. **应期**——**先数法定年，再落月日，再分年**（卯数六→六年；九年相守，第八年作生地）
11. **断后续**——主事断完再问「之后引出什么」（末传入墓→葬埋收殓；归支→交割；空→无着落）

**先定调，后抓象。不是看到一堆象再凑事。**

**取舍**：能成链、能落物、能应期者说；余者不说。**「不发用，不可乱断」。**

## 二·五 取象（象是生出来的，不是查来的）
**象 ＝ 名义 ＋ 体性 ＋ 位势 ＋ 生成**

**名义即象**：子孳·丑纽·寅引·卯冒·辰震·巳起·午萼·未昧·申伸·酉老熟·戌灭·亥核
　　　　　甲押·丙炳·丁亭·庚更·辛新·壬任·癸揆
**体性**：木内虚·火内暗·水内明·金杀性在外
**位势**：寅落申＝高处｜午落戌＝灯在库中｜酉落亥＝厕｜辰落亥＝水边

**生象九法**（象不够时用）：
合取（亥高处＋营室＝楼台；丑牛＋田＝犁）｜邻取（卯舟→寅橹；亥厕→戌浴室）｜
对取（亥管→巳钥；卯前门→酉后门；酉刀→卯砧）｜三合（申湖子江辰池）｜
借取（天谗在酉→申医；卯私门→沙门）｜推取（巳灶→锅→庖人；申医→药）｜
转取（未服→孝服→雪；酉降→恩泽→赏赐）｜造字（丑未＝魁；酉亥丑＝润）｜
藏干（寅藏丙故火炬；申藏壬故河池）

**次序**：抓主象→定名义→看体性→看位势→生成→成画面
**画面**：土塞东门｜灯在库中｜婢死于厕｜大树在门｜雷击木｜灶下灰中

## 八·五 断病专项（详见 kb/占病.md）**勿从三传起手**

**第一步：看日上／支上**（日干为上部，支辰为下部）
- 「上下俱脱」＝日上泄我＋支上泄/克我 → 虚损、泄泻

**第二步：定脏腑**（支）与病性（将）
- 亥子肾｜丑未脾腹｜寅卯肝胆｜巳午心目血｜申酉肺齿骨｜辰戌脾胃
- 蛇惊搐棒｜勾迟滞肿｜虎血光急痛｜玄暗湿疝浊｜后水湿厌秽｜阴内伤藏｜空不足

**第三步：定病源**（实案）
上下俱脱→泄泻寒热｜四午乘虎→癫狂｜辰加亥→血瘿｜寅＋玄＋闭口→瘫痪｜
火加旺地→发狂｜火墓戌→阴尽而喘｜申加未→鬼神之状

**第四步：定轻重与禁忌**
- 四课俱下贼＝绝阴，主速死
- **午为天之真火克日 → 不宜灸；午为天医 → 不宜服药**
- 空≠无，主「偏」（偏空）
- 有救：月建旺身、本命上神长生、日上子孙、制鬼之神＝良医

**第五步：定日数**
- 三证合一：**病象＋死地（长生）＋年数（数法）**，缺一只作「关口」
- 数「几见」：日上＋支上＋三传同计（四午＝四个病神）
- 见几处即几倍之（28日→两见56日）

**治法亦从课出**：如「决坤申水、通艮寅风」，闭口则通之
