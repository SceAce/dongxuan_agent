# 一式多断（据《断案新编》批注整理）

> 同一课，按十类事分别作答。这是邵彦和断案的真面目。

## 十类事固定次序
**天时 → 行人 → 出行 → 疾病 → 胎产 → 婚姻 → 求财 → 仕宦（功名）→ 家宅 → 兵**

## 天时（19 条实证）
| 象 | 断 |
|---|---|
| 天罡加亥，水运乎上 | **必有雨** |
| 天罡指阳 | **主晴** |
| 水在上皆落空亡，罡空指亥 | **阴而不雨** |
| 课传六阴 | **濛阴之象** |
| 忽然有雨，旋见日出 | **后成阴晦** |
| 风雨不久，云开日见 | 短雨 |
| 求晴得晴，求雨得雨 | 应人所求 |
| 金水母发用，水库临干 | **主有雨** |
| 水升火降，然水神不现 | **无雨** |
| 晴占则晴，雨占更甚 | 随所问而应 |

**要诀：看天罡所指（孟仲季）、看水神有无、看空亡。**

## 疾病（6 条实证）
| 象 | 断 |
|---|---|
| 肝胆受病 | 或大小肠之疾 |
| 心肾二经之症 | 或齿疼喉痛，**不妨** |
| 脾肾二家之病 | **初病愈，久病凶** |
| 肾水枯涸 | **病势极笃** |
| 新病即愈 | 久病不宜 |
| 遇医 | 防复发 |

**要诀：以支象定脏腑，以新久定吉凶。同是肾病，新病愈、久病凶。**

## 行人（4 条）
在途／未动／未归／归而复出
**要诀：看天罡加孟仲季；加孟未动、加仲在途、加季已至。**

## 出行（10 条）
眷属俱行之象／未决／不果／改期／有轮无马／水路不吉陆路更凶／
水陆皆吉／求官利余不宜／防遇雨不利正二六月／玄武发用中传游都须防盗贼

## 婚姻（2 条）
以夫就妻不顺／六月夜占可用
**要诀：同一课，换月换昼夜，结论可变。**

## 求财
难得／必有将伯之助／百般耗折或为子孙蠹耗／宜得阴贵人之财／因财生祸

## 家宅（4 条）
身就他人／干支互生人宅两旺／凡事昏昧合中却有异心／
玄武发用倘有近水房屋应遭盗贼

## 各事类的专属判据（据批注归纳）

### 天时
1. **天罡所指**：加孟（寅申巳亥）→ 有雨；加仲（子午卯酉）→ 阴；加季（辰戌丑未）→ 晴
2. **水神有无**：三传见亥子、或玄武、或天后 → 有水气
3. **空亡则减**：水神空 → 阴而不雨
4. 六阴之课 → 濛阴
5. 金水发用、水库临干 → 主雨

### 疾病
1. **以支象定脏腑**：丑未脾胃、亥子肾、寅卯肝胆、巳午心、申酉肺
2. **以新久定吉凶**：新病即愈，久病凶
3. **六阴、上下俱脱** → 虚损吐泻
4. 支上见墓 → 病沉
5. 遇医 → 防复发

### 胎产
1. **胎神**：甲己酉、乙庚申、丙辛未、丁壬午、戊癸巳
2. 胎神空 → 未孕
3. 上克下发用 → 男；地克天 → 女
4. **润下局 → 易产**；六阴 → 产迟
5. 支上破碎 → 手术

### 婚姻
1. **日上神空 → 我无意**；本命空 → 我不愿；支上空 → 对方无意
2. 干支相害 → 不和
3. 财爻（男占）／官星（女占）之旺衰
4. **换月换昼夜，结论可变**（例九：六月夜占可用）

### 求财
1. 财爻空 → 难得
2. 财与财库俱破碎 → 不成
3. **财以青龙为类神**（不只财爻）
4. 因财生祸（财生鬼）
5. 将伯之助（得人助）

### 仕宦
1. 禄空 → 位不实
2. 官空 → 无权
3. 末传破墓＋贵填实 → 方有济
4. **必有贵力异遇，虚而不实**（例九）

### 家宅
1. 支上神空 → 宅基未定
2. 支为日墓 → 宅中有旧冢
3. 干支各乘墓 → 人昏宅暗
4. 白虎生支 → 宅生白蚁
5. 人坐宅墓／宅坐人墓 → 耗散

### 行人
天罡加孟 → 未动；加仲 → 在途；加季 → 已至

### 出行
1. 驿马空 → 马空难行
2. 三传回环归支 → 去了又回
3. 关格（辰加四仲）→ 路阻
4. 水路／陆路之别看支象

### 兵
1. 主客之分（先起为客）
2. 勾陈上下相生不战、相克必战
3. 能胜而敌有救兵 → 不可追

## 前程仕进类（补录，据 p178–p208）
### 求财
- **二传皆子孙，不求财而财自至**（甲子日）——子孙生财，不必强求
- 初为财而临六害，中末皆脱干气 → 只宜守

### 仕宦
- **官煞旺，不利仕途**（甲子日）
- **三传遁生，当有荐**（壬寅日）
- 三传遁生 → 有人荐举

### 家宅
- **宅有贵气，或贵官长者**；旧房或有子孙在朋友上用情，致耗（甲子日）
- **破碎临宅，宅宇不能无损**（壬寅日）

### 疾病
- **不思饮食，医有速效**（甲子日）——病轻而药灵

### 出行
- **防有口舌牵连**（甲子日）

### 天时
- **久晴无雨**（甲子日）
- **午火发用迤逦生土，主晴**（壬寅日）——火土相生则晴
- 初传空陷而末传作水长生 → 亥日当有风雨

### 兵
- **权不自己，出兵不安**（壬寅日）
- 避难逃生之格 → 不利

### 埋葬
- 发贵；但丑上午相穿，**防兽穴，或水穿激**（甲申日）

### 解曰要语
- 「干为尊，支为卑；**干往加支，乃尊就卑也**」
- 「**末助初传，先难后易**」
- 「日阳辰之阳，辰阴日之阴，名**杂课**」
- 「**墓神逢空，反吉**」——墓空不主昏滞
