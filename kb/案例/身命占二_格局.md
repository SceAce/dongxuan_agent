# 身命占·格局（据《论命秘要》二十四格、十六局）

## 一 二十四格（看本命所加之支与所乘之将）
| 格 | 成格条件 | 断 |
|---|---|---|
| **跨青龙** | 本命子，加于寅（寅为青龙） | 极贵台阁之命；带蛇虎冲克则「跨龙不住」 |
| **倒跨青龙** | 子加寅上，寅乘青龙加于其上（龙来就我） | 大富贵；冲克兼空亡则不然 |
| **双骑龙背** | 本命辰加寅，或寅加辰 | 富贵奇局；最怕申戌来冲 |
| **二龙御命** | 本命子，寅加其上，又得辰为上龙加寅 | 贵气之格；最怕无气、冲克 |
| **龙化土蛇** | 本命寅，加于巳（蛇之本家），腾蛇乘之 | **贱命**；反喜来冲；多生富贵之家 |
| **土蛇化龙** | 本命巳，或带蛇临寅，吉神拱护，太冲六合居有力地 | 化则显；龙空被冲则「化而不化」，反贱；多生贫贱之家 |
| **乘虎登天** | 本命午带白虎临亥，或本命申加亥 | **威镇边夷，公侯之命**；无气则为无赖恶徒 |
| **履虎尾** | 本命未，或本命临未 | 得吉助则贵；无吉则术士吏卒之流；狐假虎威 |
| **立虎首** | 本命酉，或本命临酉 | **折冲万里，功名盖世**；无气则抱惊惧之心 |
| **双骑虎背** | 本命申，又乘白虎 | **英豪**；最喜有气、喜制伏；武好杀、文轻刑 |
| **虎化狸** | 本命申加戌，或带白虎临戌 | 军座吏役或凶恶悍徒；无气并空则为朱门饿殍 |
| **狸化虎** | 本命戌加申，或带白虎，得寅立有力处、有气、吉将助 | 化则贵（白屋出公卿），不化则贱 |
| **司命天门** | 本命之神加亥，带贵常龙后合朱并四马皇书皇恩 | 掌枢秘之职；凶将并空或冲克则不得司 |
| **天门不开** | 本命之神作闭口临亥，或亥作闭口 | **有大志而不得伸，寒儒之命** |
| **明入天门** | 本命作太阳，或亥自作太阳，本命立其上 | 富贵；不怕冲合空亡；忌无气则为寒士 |
| **暗入天门** | 本命上乘玄武临亥，或亥自作玄武 | **绿林豪杰或乱世奸雄**；无气逢良将则为猥琐小使 |
| **坐守地户** | 本命加巳，带贵常勾空 | 看财虏；有气则中人产业；无气带凶将则至贫薄 |
| **来拱地户** | 本命辰加午（往来求巳） | 中格之极富；别宫文明星照应则以财得官 |
| **朱雀束翅** | 本命上乘朱雀临亥子丑（雀落水） | **有七步之才而不得展** |
| **朱雀腾辉** | 本命带朱雀临寅卯辰巳午 | **文章盖世，官由翰苑**；无气带凶将则寒儒 |
| **四墓交错** | 本命属土加于四土之上 | 丰厚有财产；别宫透秀则为贵；无气带凶将则贫困 |
| **河魁贯甲** | 本命戌加寅 | 宜修武业；别宫透文明星则文武全备 |
| **甲贯河魁** | 本命寅加戌 | 同河魁贯甲，有气得吉助即贵命 |
| **朱勾拱拜** | 本命午加辰，或本命乘火临辰 | 性刚好辩、有传贵；无气则逐日讼斗 |

### 化与不化（要诀）
> 「大抵**化则贵，不化则贱**，不可一概而论。」

## 二 十六局（看三传与身命）
### 五局（三合成局）
| 局 | 三合 | 名 |
|---|---|---|
| 从革 | 巳酉丑（金） | **庚星呈瑞** |
| 炎上 | 寅午戌（火） | **祥光来拱** |
| 润下 | 申子辰（水） | **帝座渊穆** |
| 曲直 | 亥卯未（木） | **青帝施恩** |
| 稼穑 | 四季土 | **稳坐中宫** |

**五局总断**：喜生命生身，有吉将扶助，别宫有情，居时令旺气 → 富贵奇局。
刑害冲破、身命带凶将、别宫无情 → 按轻重较量荣枯。
**在空亡则分三限之优劣。**

### 四局（三传方位）
| 局 | 三传 | 名 |
|---|---|---|
| 北方秀气 | 亥子丑 | **北斗司权** |
| 南方秀气 | 巳午未 | **南极献图** |
| 西方秀气 | 申酉戌 | **西方专美** |
| 东方秀气 | 寅卯辰 | **东海探珠** |

**断**：喜生命生身、吉将扶助、别宫照应、居旺相 → 大富贵。
刑害冲破身命、凶将入传、别宫无情 → 贫薄。

### 七局（反吟、本宫、连茹）
| 局 | 条件 | 名 |
|---|---|---|
| 坎离交泰 | 本命亥子丑临巳午未，或反之 | 反吟三传；有气吉集则发福，无气凶将则始终贫困 |
| 兑震投合 | 本命寅卯辰加申酉戌，或反之 | 反吟三传；同前看 |
| 周天守 | 本命坐本宫不动，自本宫作三传 | 喜丁马有气入传、吉将 → 发富发贵 |
| 红云隽秀 | 寅卯辰加亥子丑，或反之，从命上发用入传 | 喜吉神；带凶煞则秀而不秀 |
| 林火扬光 | 寅卯辰加巳午未，或反之，从命上发用 | 同前 |
| 天合北极 | 申酉戌加亥子丑，或反之，从命上发用 | 喜吉将、嫌空破；旺相则好，休囚则不合作 |
| 火明西岳 | 巳午未加申酉戌，或反之，从命上发用 | 旺相有气、无蛇虎凶将 → 必峥嵘 |

## 三 要诀
> 「欲推身命，**先察格局**；人有妙局奇格，理宜触类旁通。」

> 「勿以有格有局而顿以贵许，无格无局而骤以贫称。盖**有格有局亦有穷寒士，无格无局亦有富贵贤人**。」

> 「有格局者宜观其为成为破，不入格局者宜详其有情无情；遇破者虽有格而不贵，有情者虽无局而不贫。」
