## 补录二（抽样页 s260–s660，前程仕进类为主）
### 关键批注原句
- 「**六壬贵人以卯为官星**」——官星之取
- 「戊以申为长生学堂，**入在空亡**」→ 「**贵而无位**」（刘干运案）
- 「日上空亡，**到好处不中事**；勾陈乘子息，乃是**虚勾**」（方县尉案）
- 「**行年在酉，从酉数至辰八位为八年**」——数位定年
- 「丑加酉，丑八酉六，**得十四**」——两数相加
- 「日上酉六、辰上午九，**六九五十四**」——相乘
- 「**干支夹定三传**，更三四课及初传俱是鬼，有官人欲赴任，为**催官符**」
- 「**末禄空亡，上任不久**，必主尊堂服动」
- 「**六壬玉成歌曰：日鬼加辰两位，门中官病两相侵**」
- 「**日鬼加辰两位**」——两处见鬼则官病并至
- 「**遍地贵人**」→ 主在任多差使兼权摄
- 「**太常到酉上败，是进败也；酉在日后，是退败也**」——进退俱败
- 「**初传日贵，传归夜贵，自治事终反不治事**」
- 「**顾祖，何能赴任**」
- 「一味投绝，又自日传夜」
- 「**墓神覆干，胎神落空，产难**」
- 「**六合内戳，带刑为用，不吉**」

### 新增判据
| 判据 | 断 |
|---|---|
| 贵而无位 | 贵人空、长生空 → 有贵名而无实位 |
| 到好处不中事 | 日上空亡 → 临门一脚落空 |
| 虚勾 | 勾陈乘子孙 → 空自勾连 |
| 干支夹定三传 | 凡事皆紧、被夹住 |
| 遍地贵人 | 多差使、兼权摄 |
| 进败／退败 | 太常临败地，进亦败退亦败 |
| 顾祖课 | 何能赴任（去而复回，不能远行） |

## 装配规则（零件→结论）
四套只给零件，须按下表装配：

| 零件组合 | 结论 |
|---|---|
| 官星临死绝 ＋ 长生空 ＋ 末传天空 | **贵而无位**（有贵名无实位） |
| 日上空 ＋ 三传吉 | **到好处不中事**（临门一脚落空） |
| 勾陈乘子孙 | **虚勾**（空自勾连） |
| 末传禄空 ＋ 干上官星 | **上任不久** |
| 太常临败地 ＋ 末传不吉 | **进退俱败** |
| 三传顾祖 ＋ 有任可赴 | **何能赴任**（去而复回） |
| 遍地贵人（三四见） | **多差使兼权摄** |
| 干支夹定三传 | **凡事皆紧、被夹住** |

**装配原则**：单个零件不定吉凶，两三个同指才下结论。

## 补录三：胎产子息类（s386–s404）
### 断子息数目
- **身宅三传俱是酉**，酉为兑、兑为少女，六合乘酉亦是女 → **五女**（三传日辰俱见酉，故主五女）
- **行年上见卯为震、为长男**，酉来合丑而卯相冲，上见玄武盗耗 → **男胎不成**
- 断数目：**以所见之支数之**（三传日辰俱见酉＝五见＝五女）

### 断不育之因
| 象 | 断 |
|---|---|
| 支来就干 | 主子显父 |
| 鬼入宅 | 主山来处不合 |
| 太阴为鬼、丑为墓加亥 | 猪圈污秽 |
| 宅中有上穹像不合触 | 缺子 |
| 酉为贵人、遍地贵人 | **贵多不贵，两头不得** |

### 断子之将来
- **三传干支皆是贵人** → 此子日后必不服、心有回家之意
- **丁以酉为妻，妻后自有子** → 不必过房

### 断产（母死子存）
- **「支是母兮干是儿」**
- 支受克、母发用、传归凶将、**虎乘墓入内门** → **母死**
- 干得旺相之气 → **儿存**

### 数法补
- **酉六未八，六八四十八** → 相乘
- **丑八酉六，得十四** → 相加
- **日上酉六、辰上午九，六九五十四** → 相乘

| 事类 | 批注 |

| 胎产 | **儿虚母实，恐不成妊** |
| 婚姻 | **昼占男吉，又嫌其空** |
| 求财 | **财与贼俱，防有失脱** |

| 天时 | 占晴不晴，占雨不雨 |

解曰：「寅乃日禄，夜乘白虎，是**好者却变而成恶**矣。申乃日鬼，昼乘青龙，是**恶者反变而为好**矣。但**来去俱空**，其好恶不过似山上浮云、水中明月已耳。」

**要点**：禄乘白虎则好变恶，鬼乘青龙则恶变好——**吉将凶将可翻转所附之神的性质**。

## 补录五：疾病类三课（s512–s524）

### 辛卯日（曲直局，财化为鬼）
| 事类 | 批注 |
|---|---|
| 天时 | **天罡指阳，传成木局，不雨而风** |
| 兵 | 未见全美 |

| 仕宦 | **三传生贵，占官最吉** |
| 疾病 | 或心肾之疾 |

**解曰**：「三传木局，干之财也，**反生起干上午火，来刺辛干，是财变而为鬼矣**。」
「末传如足而乘遁丁，有动而不能自己之象」→ **足下乘丁，势在必行**。
「三传生贵，如以财而与贵人也；彼既受生，自然不暇为我刺矣，故有**告贵贿成**之说。」

**要点**：三传生贵（财生官）→ 占官吉、行贿可成；三传财化鬼 → 因财致祸。**同一个局，问官则吉，问财则祸。**

## 补录二十一：丁卯日第八课（重审／印乘轩，s614）

| 失脱 | 自还 |
| 疾病 | 有祟；**昼占甚危** |
| 求财 | **宜远投人，重求轻得** |

| 胎产 | **末传刑胎神，防堕** |

|---|---|

| 初末马动 | 殆无宁刻（忙乱） |
| 就婚贵家吉，娶即非正 | 婚之正偏 |
| 求财宜远投人 | 重求轻得 |

## 补录二十四：乙丑日第八课（重审／天狱，s650）
| 事类 | 批注 |
|---|---|
| 出兵 | **多在中途止息，大宜防夜** |
| 天时 | **水升火降，当有雨** |

## 补录二十五：癸亥日第三课（蒿矢，六阴，s049）
| 事类 | 批注 |
|---|---|
| 兵 | **阴不备，利为客** |
| 天时 | **晴** |
| 行人 | **有贵人带信至**；即回 |
| 捕获 | 可得 |
| 出行 | **大利** |
| 失脱 | **主多破败** |
| 疾病 | **肾虚或肝经之病，虽淹，可以无事** |
| 胎产 | **阴极阳生，孕主男，产速而安** |
| 婚姻 | **酉乘太常，正婚姻落筵；或开张衣食店，当茂盛** |
| 求财 | **财亡复获** |
| 仕宦 | **甚吉** |

### 解曰
- 「蒿矢之课，**六阴相继**……喜二传格合回明，有月缺潮回之象，**吉可渐成，凶可渐散**，但**阴阳不备，终不完美**耳」
- 「酉为破碎败神……幸初传日鬼，遥力轻」
- 「中末两贵相加，乘丁递生支上酉金育干，**所以财亡复获**」
- 「丁马作日德，**利有攸往**」

### 新判据
| 判据 | 断 |
|---|---|
| 月缺潮回之象 | 吉可渐成、凶可渐散（渐，非速） |
| 阴阳不备 | 终不完美 |
| 丁马作日德 | 利有攸往 |
| 财亡复获 | 先失后得 |
| 阴极阳生 | 孕男，产速而安 |
