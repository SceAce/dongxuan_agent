## 宅墓例八（壬寅日第八课，知一，中末落空）
### 判据原句
- 「**辰为壬水之墓，加日上是墓身也**」——墓加日干＝墓身
- 「**未为寅木之墓，加辰上是墓宅也**」——墓加日支＝墓宅
- 「**干支各乘墓神，占婚不吉**」
- 「**财爻巳空，求之无益**」
- 「**末传青龙破墓，更贵填实，方为有济**」——末传破墓＋贵人填实，方解
- 「**白虎乘子生支，宅内恐生白蚁**」
- 「**太常夜乘未伤干，疾病必因喜宴而致**」
- 「**天后乘墓临干昏迷，必因女色而致**」
- 「幸**末传戌土乘龙破墓**，当有父母尊长提撕而警之」
- 「惟**年命有木可救**」
- 「神后加未，夜乘六合，主有**邪魔鬼祟**」

### 按九类事分列（同课异问）
| 事类 | 批注 |
|---|---|
| 家宅 | 墓身墓宅；白虎乘子生支，宅内恐生白蚁 |
| 婚姻 | 干支各乘墓神，占婚不吉 |
| 求财 | 财爻巳空，求之无益 |
| 仕宦 | 末传青龙破墓，更贵填实，方为有济 |
| 疾病 | 太常夜乘未伤干，必因喜宴而致；天后乘墓临干，必因女色而致 |
| 胎产 | 下强上弱，孕乃成女 |
| 出行 | 水路不吉，陆路更凶 |
| 行人 | 天罡加孟，尚未起行 |
| 天时 | 墓神覆日，水莲乎上，青龙刺日主雨 |
| 兵 | 先难而后获 |

### 课象批语（旁注）
- 避都、地医、大煞、羊刃、旬空
- 「巳畏子戌」「刃虎叠逢」「财亡妻失」

## 本书体例（据序文）
> 「邵公《六壬断案》看似固定问一事而占一课，而实是**一式多断**，读者再融会贯通《直指析义》的解释，活用其他占例，而一式多断；邵公《断案》最精彩最奇特之处，正是在于虽是同一课式例，亦漫应之……」

**核心：一式多断。** 同一课，按九类事分别给出结论，不是只答所问那一件。

### 九类事（固定次序）
1. **兵** 2. **天时** 3. **行人** 4. **出行** 5. **疾病**
6. **胎产** 7. **婚姻** 8. **求财** 9. **仕宦** 10. **家宅**

### 三种注释层次
1. **邵公原断**（断曰）
2. **解曰**（判据解释，如「辰为壬水之墓，加日上是墓身也」）
3. **《六壬直指析义》引文**（课体解释）
4. **容平補解**（末附）

## 例十二（辛卯日，卯加卯占家宅）
### 解曰原句（可直接用）
- 「**六壬财以青龙为类神**；青龙乘子水旺相，主**财气甚旺**」
- 「**卯酉主门户**；卯上乘朱雀，**口舌是非之神**」
- 「**子右加亥字，合成孙字**，此用来测字亦可通也；天机示现，本就无定法，端看个人心灵感应而定」
- 「**三传四课水旺，又在亥月占，水极旺，必主泌尿系统出问题**」
- 「**壬日墓在辰**；辰遁甲干乘螣蛇也」
- 「亥数四，身与初传重见旺则**相倍之**，故四四一十六年寿」
- 「**旺禄临身徒妄作**」

### 断语
「宅上帝旺，财物兴隆……子作亥，似孙字，今年子及孙常进学。末传门户上有不宁，乃户役事。门上不合安符，主不时吵……财禄甚稳，家当大发，但身有膀胱疝气及阴水气之扰，尚有四四一十六年寿，当以阴肿而亡。」

### 要点
1. **财以青龙为类神**（不只以财爻）
2. **卯酉主门户**
3. **测字法**：子加亥合成「孙」
4. **旺衰加倍**：旺则相倍之（四→十六）
5. **旺禄临身徒妄作**

## 例十五（戊申日第九课，润下）
| 事类 | 批注 |
|---|---|
| 兵 | 破碎临干，不吉 |
| 捕 | **盗在正西道旁**；玄武发用，中传游都，须防盗贼 |
| 疾病 | **伤风肾竭之症** |
| 胎产 | **孕生女，润下易产** |
| 婚姻 | **男女皆败，将来不吉** |
| 出行 | 主牵连下贱，未能散耦 |
| 求财 | **必有将伯之助**；败气临干，占者当有破败之子 |
| 家宅 | **人坐宅墓、宅坐人墓**，不无耗散 |

### 判据原句
- 「干上虽乘破碎，然**三传水局，财固满路**也」
- 「**润下之卦，事动众课**；或托人作合」
- 「人坐宅墓，宅坐人墓，不无耗散」

### 新得
1. **润下易产**——水局主生产顺利
2. **游都**（捕盗用神）：玄武发用、中传游都 → 防盗
3. **人坐宅墓／宅坐人墓**：日干临支之墓，支临日干之墓
4. **将伯之助**——求财得人助

## 例十二（壬子日第一课，三奇／伏吟）
| 事类 | 批注 |
|---|---|
| 兵战 | 防 |
| 天时 | **晴占则晴，雨占更甚** |
| 捕 | **夜占即家中人作贼** |
| 行人 | **未动** |
| 出行 | **不果** |
| 争讼 | **田产致，可和** |
| 婚姻 | 不利 |

解曰：「**亥为德禄，干发用**，何其幸也。**如不守其禄，而贪心未已**……且**课体伏吟，宜静而不宜动**耳。」
「中传之子，以冀兴旺；则末传卯子**无礼相刑**，刑狱之遭其能免乎。」
「**病肾经，未能即愈**」「**男子之神伏吟，占产尚迟**」「**支干比和，且乘旺禄**」

## 例十八（癸巳日第十课）
| 事类 | 批注 |
|---|---|
| 葬 | **吉，固有益** |
| 兵 | 美中不足 |
| 天时 | **申金水母发用，辰土水库临干，主有雨** |

解曰：「**辰土鬼墓临干甚凶**，幸**末传寅木子孙相救**；乃初传支上申金刺制寅木，难为救矣。」
「干上见墓神刺，支上见刑不利」「中途可归」「墓就生稍利」「墓神覆干，胎神落空，产难，胎……」「六合内戳，带刑为用，不吉」

**要点**：墓临干凶，末传子孙可救，然若子孙被制，则救不成。**救神须验其能否得力。**

## 例十九（癸日第十二课，蒿矢）
| 事类 | 批注 |
|---|---|
| 兵战 | **先凶后吉** |

解曰：「**蒿矢神遥日，力弱难施**；兼末土空亡发用，尤无力……」「**干上寅木脱气**，落空，应见**走失脱耗**之事，宜慎宜防」「**蒿矢旬空，归而未果**」「犹豫不决，尚有阻滞」

**要点**：遥克而空，力更弱；主「欲为而不能为」。

## 例二十九（丙戌日第八课）
| 事类 | 批注 |
|---|---|
| 兵 | **主能胜客，余客有救兵，引去不可追之** |
| 天时 | **水升火降，然水神不现，无雨** |
| 家宅 | **凡事昏昧，合中却有异心；幸财气有情，获有一点生意** |

解曰：「**戌为墓神，来覆日上**，两蛇夹之，不能免也；戌来墓丙……」「**巳加子乘空，灶无故自破**」「卯遂加戌，戌又墓巳，巳又投于子水之中」「丙以申为财，**因财生祸**」

**要点**：
1. **墓覆日上，两蛇夹之** → 不能免
2. **巳加子乘空 → 灶无故自破**（器物自坏之象）
3. **因财生祸**——财为祸源
