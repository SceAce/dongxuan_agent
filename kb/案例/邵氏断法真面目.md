# 邵彦和断法的真面目（据原文重读）

> 我先前建了流程、七层、装配、三问、格名、三程、复验。
> **重读原文，发现那些多半是我的发明。邵彦和的方法极简。**

## 一 一句一象，并列不推导

**何三公案【断】原文**：
> 「干支带墓」——一句。
> 「第四课见子鬼发动，却又传归日上」——一句。
> 「六月死神在戌作蛇，主有伏尸」——一句。
> 「主不出八年，痨病来缠，当死五人」——一句。

**四句，四件事，各自独立。没有串联，没有装配。**

**格式：`象 → 事`。一句一个。**

**弹射格案**：
> 「**一主**妇人患血气；**二主**门户不宁；**三主**婢妾出去；**四主**家主患口舌之疾。」

**一、二、三、四，并列四条。** 每条各指一象，互不推导。

## 二 断语的结构

```
① 定调一句（格或势）
② 逐象直说（一象一事，可并列三到五条）
③ 结果一句（几年、几时、死生）
④ 办法一句（若有）
```

**张九翁案**：
- 定调：「干支皆受上神来生，**利宅不利人**」
- 逐象：「干上发用归传支，末传亥脱干而生支，因充役费用」｜「又与姓陈吏人不和」｜「尊长末后为儿娶妇，所费尽坏家计」
- 结果：「**十一年间**阴人守寡，家产四分」
- 【析】才说：亥四寅七＝十一

**何三公案**：
- 定调：「干支带墓」
- 逐象：四课子鬼发动传归日上｜死神在戌作蛇主伏尸｜宅中旧墓前后尸骸
- 结果：「**不出八年**，痨病来缠，**当死五人**」
- 办法：**掘之**（何公掘得十四穴）

## 三 【析】不是解释，是「换算」

**我一直以为【析】是事后说明。错。**

| 案 | 【断】给的 | 【析】给的 |
|---|---|---|
| 张九翁 | 十一年 | **亥数四、寅数七，乃十一年也** ← 数是算的 |
| 王德卿 | 二十六年寿 | 亥四数，四个亥，四四一十六年 ← 数是算的 |
| 叶七秀才 | 十三年疝气亡 | **亥四子九，四九三十六**…金死于子 ← 病＋死地＋数 |
| 童保仪 | 四年败，六年败尽 | 卯酉俱六数 ← 数是算的 |

**【断】给结论，【析】给换算过程。**

**所以【析】里的五行生克、长生、数，不是"推理"，是"换算"。**

## 四 办法从象出，不是另想

| 原文 | 象 |
|---|---|
| 若**速移此坟**，可保佑性命，否则戊午年必见凶 | 坟之象（干支带墓、伏尸） |
| 若**改干亥山向、决宅水东流**，戒酒色，犹可延 | 宅水停之象（宅上亥） |
| 此课**可改门户**，否则口舌立至 | 门户不宁之象 |
| 若**寄出家**，可以免灾 | — |
| 要好**决坤申水、通艮寅风** | 真闭口之象 |

**格式：「若【改某处】，则【免某祸】；否则【必见某凶】。」**

**办法总是落在「象所指的那一处」上。** 象说门户不宁 → 改门户；象说水停 → 决水。

## 五 邵彦和不用「推理」，用「翻译」

```
象  →  事
午加申  →  马在路上
酉为婢，六合加之  →  婢子做媒
辰加亥为天后  →  血瘿
```

**一步到位。没有中间环节。**

**我做的"七层→串联→装配→三问"，是把一步变成五步。**

## 六 他的「严谨」在哪

**不在流程，在三处：**

1. **象必须指得出来**——「若申不空，则不可乱断」（申空是前提，不空就不能这么断）
2. **数必须算得出来**——十一年＝亥四＋寅七
3. **条件必须交代**——「若春占主水涨，今冬占必有大雪」（同一课，季节不同，断不同）

**他的严谨是"每句有据"，不是"每步有流程"。**

## 七 我要改的

| 我做错的 | 应该 |
|---|---|
| 建流程（七层→装配→三问） | **一象一事，直译** |

| 办法另想 | **办法从象出** |
| 追求"多层同指" | **一象足矣，只要指得出** |

**一句话：六壬是翻译，不是推理。**
