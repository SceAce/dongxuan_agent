# 占病（据断案与身命课实证）

## 一 起手法（最要紧）
**先看「日上神／支上神」这一对，不从三传起手。**

> 「**日干为上部，支辰为下部。**」（张逸士案）

| 位 | 主 |
|---|---|
| 日上神 | 病在上半身 |
| 支上神 | 病在下半身 |
| 日干 | 上部 |
| 支辰 | 下部 |

**「上下俱脱」**＝日上泄我 ＋ 支上泄我／克我 → 虚损、泄泻、五痨七伤。

## 五 定应期与死期（三证合一）
**病象（支＋将）＋死地（长生）＋年数（数法），三者同指方可断死；缺一只作「关口」。**

| 案 | 数法 | 应 |
|---|---|---|
| 张逸士 | **巳亥俱四，申数七，四七二十八**；两处皆见 → **五十六日** | 死二十八日，或再历二十八日 |
| 王县丞 | 四午＝四个月病符、四个天鬼 | 三十七岁癫，三十九岁复发，**四十岁太岁到寅死** |
| 徐孺人 | 五十四五之间 | **五十四岁瘿破血出死** |
| 叶七秀才 | 亥四子九＝十三 | 十三年疝气亡 |

**要点**：
- **数见几处，即几倍之**（28 → 56）
- **太岁到病神所在之支**，即为应年（王县丞：太岁到寅，上见午为死神）
- 死神乘白虎克日、再空亡者，为「黄泉鬼」，主速死

## 六 救治与不宜
| 象 | 断 |
|---|---|
| 制鬼之神 | **即为良医**（乙丑日案：午火制酉金，故医在午） |
| 德神临 | 有救 |
| 本命上神长生 | 可救 |
| 遇医 | 防复发 |
| 病神有制而无补 | 治标不治本，反复难愈 |

## 七 忌
1. **不可从三传起手断病**——先看日上／支上
2. 见凶不骤断死——须三证合一
3. 煞空≠无事（病符空仍主有此事而不重）
4. **「上午」这类要分清是日上、辰上、传上**——王县丞案「上午、辰上午、中传午、末传午」共四午，数法由此起

## 八 数「几见」之法（重要）
**同一支在「日上＋支上＋三传」中出现几次，即算几见。**

实证（王县丞案，甲寅日未将卯时）：
- 日上午、支上午、中传午、末传午 → **四午**
- 断：「四个月病符、四个天鬼、四个白虎，所以丧四子」

**故数法不能只看三传。** 四课的上神（尤其日上、支上）与三传同计。

| 处 | 计入否 |
|---|---|
| 日上神 | ✓ |
| 支上神 | ✓ |
| 初／中／末传 | ✓ |
| 其他四课 | 视情况，作旁证 |

## 九 断病实战九案（据断案原文，逐案取法）

### 案一 某占病（戊午日亥将戌时，别责）——疫气入宅
- 「**天鬼午，受病鬼之生**，犯了东岳城隍香火神，乃**疫气入宅，主合宅病**」
- 「寅正春旺之鬼，**鬼有气不止一人**，其家七口，病死三人」
- 「**中末日上三个羊刃杀，所以丧三人**」
- **法**：鬼有气则不止一人；数「几见」定几人（三个羊刃→丧三人）

### 案二 叶解元（壬辰日午将巳时，元首进茹）——酒食感风
- 「本身虽坚固，不合**传进迤逦脱气**」
- 「子与丑合作常，**因与人相会饮酒食，而喜乐太过，遂惑风邪**」
- 「**宅上见绝神**，三传丑寅卯，若非行年退却一步，定见进脱，**不可疗矣**」
- 邵氏通则：「**壬日行丑寅卯，迤逦进脱，支上又见绝神，必不可治，不问老少皆以死论**」
- 惟此行年在后一位，「引退就禄」，故不死
- **法**：**日干进脱＋支上绝神＝死证；然行年退就禄可解**。这是「忌」中见「救」的一例。

### 案三 某占病（庚辰日亥将辰时，涉害绝嗣）——血病三日死
- 「**四课俱下贼，绝阴之象**」
- 「**白虎乘午作鬼，男病主三日内死**也。何则？**无阳气也**」
- 「**不合灸，又不宜服药，此是血病**。盖**午主心，心主血**也」
- 「午是**天之真火**克日，主灸神，乘虎故不宜灸；又是**天医**，故不宜服药」
- 「涉害深为用，主**久病**」
- 「火加水，主**寒热往来**克日，主**痨血**」
- **法**：四课俱下贼＝绝阴；虎乘午鬼＝三日内死；**真火克日不宜灸，天医不宜服药**

### 案四 某占病（丁巳日未将寅时，重审铸印）——狂言发喘而死
- 「主病人**狂言发喘而死**」
- 「巳作常为用，主言语。**丁日巳用皆火**，中又蛇乘戌加巳，是**火加旺地**，故主**发狂**」
- 「**火墓戌，阴气尽**也。凡人以内阴气为主，阴日养阳，今已绝，则**阳气上攻**，而不能生阴，**阴绝阳弱，更主发喘**」
- **法**：火加旺地则狂；火墓则阴尽；阴绝阳弱则喘。**由狂到喘到死**，是一串。

### 案五 某占病（丙午日子将亥时，弹射进茹）——咳嗽狂言见鬼神
- 「定是**咳嗽狂言，见鬼见神之状**」
- 「三传金，主**肺主嗽**；而午火又加丙，**午火盛发，心神散乱**，故主**发躁狂言**」
- 「鬼神之状者，**申加未，未临宅，未主鬼神之状**」
- 「其人**死者，传归死墓**也」
- **法**：三传属金＝肺；火盛＝心神散乱；申加未＝鬼神之状；**传归死墓则死**

### 案六 徐秀才（壬戌日亥将申时，遥克）——瘫痪
- 「此课不可问试，**防今年有风疾，似乎痿痪之类**」
- 「**破碎位太常乘鬼入宅**，若无疾则有服」
- 「初墓加破上，虽空亦主**妇人有血气疾**」
- 「**甲寅加癸亥真闭口**，又乘玄武，**又是一重闭口**；寅主风，玄武亦主风，寅与亥合，故主**瘫痪**」
- 「**辰戌丑未重重壅塞，又兼闭口，便是血气不调**」
- 「要好**决坤申水、通艮寅风**，便可免此灾」
- **法**：寅主风、玄武主风、闭口主气血不通、四库重重壅塞 → 瘫痪。
  **治法亦从课出：决坤申水、通艮寅风。**

### 案七 王县丞（甲寅日未将卯时，八专）——癫狂
- 「日辰皆见午，甲寅二木，**皆死于午**，那堪中末又是午」
- 「初传又是绝神，六月午为**月病符**，**旺火蚀休木**」
- 「既无父母，亦难为子息及自身」
- 「四午来蚀甲寅，是**四个月病符、四个天鬼**」
- 「四个天地转杀、**四个白虎，所以丧四子**」
- 「**午为心，遇虎故主颠狂**」「木死于午，故为废人」
- **法**：同一支四见 → 四重病神；午为心、虎主狂 → 癫狂；木死于午 → 废人。

### 案八 徐孺人（癸巳日申将卯时）——血瘿
- 「日上午作蛇见空亡，为**偏空**」→ 空不等于无，主「偏」
- 「**日起于阴人所苦**，遂至心下不足」
- 「午为心，癸水灭午火又空亡，**是心受制而不足**」
- 「午为目，蛇扰水制又空，**自然昏暗**」
- 「**辰加亥为天后，辰坚土加血上，故为血瘿**」「天后主厌秽，癸水入辰墓，**故瘿破而死**」
- **法**：**辰加亥＝血瘿**（坚土加血）；天后主厌秽；入墓则破。

### 案九 童七秀才（丁巳日未将未时）——非病案，取「学堂」
- 「丁以**末传寅为学堂**，末寅行年卯扶，故**次年发解举**」
- **法**：末传为学堂、行年扶之，主次年得解。

## 十一 死证与救神（重要：死证不等于必死）
### 死证
- **壬日行丑寅卯，迤逦进脱，支上又见绝神** → 「必不可治，不问老少皆以死论」（邵氏通则）
- 四课俱下贼 → 绝阴，速死
- 上下俱脱（重症）
- 传归死墓

### 救神（三样，有一则可延）
| 救 | 例 |
|---|---|
| **行年退在传后** | 叶解元案：三传丑寅卯前进，行年酉退后 → 「引退就禄」 |
| **时令旺身** | 「时令在秋，壬癸水秋生，得亥子相并旺相，必不至死」 |
| **暗贵人** | 「内有暗贵人故也」 |

**断法**：见死证不可即断死，**须查此三样**。三样俱无，方可断死。

### 实证（叶解元案）
- 死证：三传丑寅卯迤逦进脱＋支上巳为壬水之绝
- 救一：行年在酉，退在传后，「虽然进其实就退」
- 救二：秋令，壬水旺相
- 救三：暗贵人
- **结果：不死，且「今冬得子」**

**一处仍凶**：「目下主服」——初传丑破碎作太常，故主孝服。

## 十二 病之「一进一退」
| 象 | 断 |
|---|---|
| 三传前进（连茹） | 病势进 |
| 行年在传之前 | 随病而进，危 |
| **行年在传之后** | **退而就禄，可救** |
| 传进脱气 | 虚损日甚 |

**断病不只看三传，还要看行年与三传的先后关系。**

## 十三 断病要看「时令推移」（非只占课月建）
**书上断病，常把时令往后推，看「病至某季」而非「占在某月」。**

实证（叶解元案）：
- 占课：**庚戌年六月**（未月，夏）
- 书上却说：「然喜**时令在秋**，壬癸水秋生，得亥子相并旺相，**必不至死**。主**今冬得子**。」
- 即：**病虽发于夏，至秋则壬水得生**，故不死。

**断法**：
1. 先看占课月建（定目下）
2. **再推后一季、两季**，看病神是否得生、日干是否转旺
3. 若后季得生 → 断「可延」「不死」，并给出转好之季

**此条最易漏。** 只按占课月建断，会把「夏病秋愈」断成「夏病夏死」。

## 十四 行年与三传的先后（再申）
| 关系 | 断 |
|---|---|
| 行年在三传**之前** | 随病而进，危 |
| 行年在三传**之后** | **退而就禄，可救**（叶解元案：三传丑寅卯前进，行年酉在后） |
| 行年**入**三传之支 | 与病同途，最险 |

**断病必查行年落在三传的哪一边。**
