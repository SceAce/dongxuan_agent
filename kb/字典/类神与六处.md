# 类神与六处（据《六壬类集》）

## 一 六处（断课的坐标）

> 「凡占六壬以**六处**决断：**日与辰**二处；**三传**共五处；**年命**共六处。年命系二处，**实是七处**。」

| 处 | 是什么 | 主什么 |
|---|---|---|
| **一 日** | 日干 | 我、身 |
| **二 辰** | 日支 | 彼、宅、事体 |
| **三 初传** | 发用 | 事之起 |
| **四 中传** | — | 事之中 |
| **五 末传** | — | 事之终 |
| **六 本命** | 生年支 | 根器、自身 |
| **七 行年** | — | 当年之境 |

**断课时，象必须落在这七处之一。落不进去的，不是这一课的象。**

## 二 类神取法

> 「**看类神为要，就于七处取来**问何事，**各于类神上决断**。」

### 一 先定类神
| 问 | 类神 |
|---|---|
| 走失奴婢（男） | **河魁（戌）、天罡（辰）** |
| 走失奴婢（女） | **太阴、从魁（酉）** |
| 财 | 财爻（我克者）；**兼取妻**（财妻同位） |
| 婚 | **六合**；男占兼妻财，女占兼官星 |
| 病 | 日干为身、支为辰；**天医、生气、丧门** |
| 官讼 | 官鬼、朱雀、贵人 |
| 文书 | 朱雀 |
| 走失牲畜 | 本属（马午、牛丑、羊未、鸡酉、犬戌、猪亥） |
| 失物 | 所失之物之本象 |

### 二 再看类神「落在何宫遇何神」
> 「此神**落在何宫遇何神**，兼取**刑冲破害、旺相死休囚**断之，又看**当令不当令、有气与无气、空亡不空亡**。」

**四问**：
1. 落在何宫（临何地支）
2. 遇何神（乘何天将）
3. 旺相死休囚（当令否、有气否）
4. 空亡否

**此四问一定，类神之吉凶立见。**

## 三 六处的用法
**同一个象，落在不同处，主不同的事：**

| 处 | 例（酉为婢） |
|---|---|
| 日上 | 我身边的婢 |
| 辰上 | 宅中之婢 |
| 初传 | 事起于婢 |
| 末传 | 事终于婢 |
| 本命上 | 与我自身有关的婢 |
| 行年上 | 今年所遇之婢 |

**故断课前必先问：这个象，落在哪一处？**

## 四 次序
```
一 定类神（问什么，取什么）
二 找类神落在七处之哪一处
三 看它遇何神、旺衰、空否
四 由此断事
```
