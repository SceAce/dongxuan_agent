# 取象法（怎么"看出"那个象，不是查表）

> 取象不是查表对号，是**按规则生成**。表只是已生成的例子。

## 一 取象的本质：位 + 物 + 势
**任何一个象，都由三样合成：**

```
象 = 位（它在哪里）＋ 物（它是什么）＋ 势（它正旺还是衰）
```

| 要素 | 例（寅） |
|---|---|
| **位** | 临申（高处）、临亥（水中）、临午（火地） |
| **物** | 木器、庙、道路、文书 |
| **势** | 长生（方生）、临官（方盛）、死（方绝） |

**同是寅**：
- 寅临申 + 长生 → 高处的**新木器**
- 寅临午 + 死 → 火地的**枯木、废材**
- 寅临亥 + 长生 → 水边的**活木、舟车**

**位变、势变，物就变。** 所以不能只查「寅＝木器」。

## 二 生象四法（怎么从一个支"生出"一个象）

### 法一 直取（本义）
支本身是什么，直接说。
- 亥＝水、厕、肾；午＝火、心、目；卯＝门、舟车

### 法二 转义（看它落在哪）
**落在某位，就带上那个位的意思。**
- 寅落申（坤为高阜）→ **高处**
- 酉落亥（亥为厕）→ **厕**
- 巳落酉（酉为金）→ **灶下金器**
- 辰落亥（亥为河）→ **水边堤岸**
- 午落戌（戌为墓库）→ **灯在库中**

**取法**：问自己「这个支落在什么性质的地方？」——高处、水边、火地、金铁处、门户、库藏。

### 法三 合成（两支相合）
**两支相合，成一物一事。**
- 辰＋亥 ＝ 堤岸＋水 → 水边
- 申＋未 ＝ 金＋鬼神 → 鬼神之状
- 辰＋亥（血）＝ 坚土加血上 → **血瘿**
- 巳＋酉 ＝ 灶＋金 → 灶下灰中

**取法**：把两支的物象摆在一起，看它们合起来像什么。

### 法四 成象（带动作，成一个画面）
**最活的一层。象不是名词，是画面。**
- 「卯加巳」→ **大树在门**
- 「戌加寅」→ **雷击木**
- 「寅加申，斫轮」→ **修剪砍伐**
- 「午加戌」→ **灯在库中**
- 「酉加亥」→ **婢死于厕**

**取法**：问「这两个东西凑在一起，会发生什么动作？」

## 三 取象的次序（先抓反常，再展开）
```
一 看什么最反常  ← 四午、四绝、全空、俱下贼、上下俱脱
二 看它落在哪    ← 转义
三 看它合什么    ← 合成
四 看它像什么    ← 成象（画面）
```

**反常处即主象。** 寻常的象不必取，取了也没用。

## 四 取象的分寸
1. **象要能落到具体物**（树、门、灯、灶、厕、柜、堤），不是抽象词
2. **象要能串**（寅＋申＋长生＝高处的活木）
3. **象要合事理**（问沉香，取木器、柜、高处；不问则不必）
4. **象不逆五行**（五行说是克，象不能取成生）

## 五 常被忽略的三类象
### 一 动作象
拆、移、埋、塞、压、断、烧、沉、漂、缠、锁
- 「丑土加卯门」→ **土塞东门**
- 「戌加亥」→ **鬼渡天门**
- 「卯加戌」→ 木入墓 → **埋**

### 二 数量象
同一支几见、几处同见
- 四午 → 四个病符、四个白虎、丧四子
- 两个亥 → 两重恩泽

### 三 空破象
- 空 → 「偏空」（有而偏，不是无）
- 破碎 → 器物有缺
- 墓 → 藏、止、不实

## 六 取象实例复盘（叶七秀才案，一句一句怎么来的）
| 书上原句 | 怎么取的 |
|---|---|
| 「丑土生辛金，故为**母**」 | 六亲（五行生克） |
| 「寅艮方，丑加之，故**艮山坟地**」 | 转义（寅在艮）＋合成（丑加寅） |
| 「**金绝于寅**，故主妻死」 | 长生＋六亲（寅为财为妻） |
| 「传见子亥，金水相生，**传见退脱**」 | 五行（金生水＝脱） |
| 「**亥为肾**」 | 直取 |
| 「**玄武主疝气**」 | 将象 |
| 「**金死于子**」 | 长生 |
| 「**亥四子九**，十三年」 | 数法 |
| 「水便陡泻，**自西北上出去**」 | 转义（子亥逆入西北） |

**九句话，用了七种取法。** 这不是查表能查出来的。
