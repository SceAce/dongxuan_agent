## 五 取象次序（人→物→事→处→变）
1. **人**＝六亲对该支所定；
2. **物**＝该支在本事类中的类神义；
3. **事**＝所乘之将，及其所临之宫的定名；
4. **处**＝所临地盘之支；
5. **变**＝所披之煞（破碎、羊刃、白虎、墓、空）。
上一层已定，下层只作修饰，不改主语。

- 类神加日干或加日辰 → **物未出宅，自归**
- 类神空亡 → 不在原处、已被挪动
- 类神受克 → 已损，但未言必失

## 本命临干上时的取象（重要）
本命所乘之神加临日干，其象**同时**是「此人」与「此事」，须取该支的**全部义项**中最合事理者，不可只取身体部位。

例（壬申日辰将巳时，女命戌）：
- 戌＝足、腿（身体部位）
- 戌＝**人力、刀、狱、山岗**（器物与势）
- 日上戌乘白虎、戌又旬空 → 断者取「足」，推出跌伤腿脚；实际是**被刀割伤手**。
- 正解：白虎＝伤、酉＝血、**戌＝刀/人力**，三者合为「以刀伤手」，手者甲乙木之象（日干壬水所生？非），实以「刃」取之。

**结论：本命临干，先问「此人今日为何事」，再取身体部位。**

## 拆字法（六壬特有，非类象）
古人于支象之外，兼用**字形相合**取象，须留意：
- **子边作亥＝孙字**（子＋亥两字相并就成「孙」）→ 主添孙。
- **子巳相加＝死字**（断案陈公献法）。
- **斗鬼相合＝魁字**。

用法：两字相邻（同宫、相连之支）时，先看能否成字；能成字者，其字义可直断。
例：壬子日占宅，中传子、支上子，干上亥，**子边作亥** → 断「进子添孙」，案验本年三月生子、十二月添孙。

## 器物相加（支象×支象）
两支相加，各取其物象，合成一事：
- **巳（灶）＋亥（厕）相加** → 灶厕不便（断案：宅水不通、灶厕不便）
- 巳（炉灶）＋酉（金/血） → 炉灶灰中（失金环案）
- 辰（堤岸）＋亥（河） → 水边堤岸（失踪案）

## 取象链的四种接法（据断案 145 条析语归纳）

### 一 支→支（一物接一物）
甲支之物，加乙支之上，则甲物落于乙处。
- 「申为磨，卯为压东门」→ 磨压门
- 「巳为灶，亥为厕，巳亥相加」→ 灶厕不便
- 「戌为山岗，宅来加申」→ 宅后逼山
- 「辰为堤岸，亥为河，亥临辰」→ 水边堤岸

### 二 支→宫（一物入一处）
甲支加于乙宫，取乙宫之义。
- 「午为妇人，午乃离，为目，入墓」→ 失明
- 「巳为双女为口，申为骨牙，勾主损折」→ 损牙
- 「巳加辰作贵，巳主双」→ 双峰文笔
- 「寅加长生之地」→ 道士

### 三 支→六亲→人
先定支，再以六亲定其人，再以所乘之将定其事。
- 「甲以巳为子息，末传戌刑未」→ 子息有事
- 「申为妻，上乘六合」→ 妻入棺
- 「酉以酉为婢，巳加酉」→ 宠婢
- 「未为眷属，天空为平地起堆」→ 眷属事虚

### 四 支→数（一物定其数）
支本身带数，重见则倍数。
- 「丁巳日，宅上卯，末传酉，俱六数」→ 六年败尽
- 「亥四数，课中四个亥，四四一十六」→ 十六年
- 「未八数，两个八年十六年，先用后一半」→ 十二年

### 五 忌：链太长则断
析语中的链，一般不超过**三节**。
超过三节（如「日上未为眷属，阴上见酉，酉属兑，兑为少女」已是四节），须有验方可立。
**断课时若需四节以上才能说通，多半是凑。**

| 亥四数，课中四个亥，四四一十六 | **重见则倍** | 16 |
| 申七辰五，三十五，空亡减半 | 相乘后**减半** | 17 |
| 亥四，相乘得二十四，折半一十二，加亥地盘四数，共十六 | 乘→折半→加 | 16 |
| 未八数，两个八年十六年，先用后一半 | 倍而后取半 | 12 |
| 亥四，主克四妻 | **数即人数** | 4 妻 |

### 通则
1. **数可加、可乘、可拼接、可折半、可倍数**，取何法由事理定。
2. **空亡则减半**（申七辰五，三十五→十七）。
3. **同支重见，其数倍之**（四个亥＝十六年）。
4. **数即人数**（亥四主克四妻）。
5. 断数须先有「事」，再取「数」；不可先算数再凑事。

### 最要紧的一条
「亥四，相乘得二十四，折半为一十二，加亥地盘四数，共十六数，五十六岁交末限」——
**同一课里，四被用了三次（相乘、折半、再加），每次取义不同。**
说明数法不是算一遍，是**按需分步取用**。

## 方位断法（据 26 条方位析语）

### 一 基本方位
- **支之本位**：子北、午南、卯东、酉西、寅东北、申西南、巳东南、亥西北。
- **卦位**：乾亥（西北）、坎子丑（北）、艮寅（东北）、震卯辰（东）、巽巳（东南）、离午未（南）、坤申（西南）、兑酉戌（西）。

### 二 断法三则
1. **类神所临之地盘支即方位**
   例：「辰为坟地」加艮方 → 「艮山坟地」；「巳为店业」临南方 → 运货至南方。
2. **以卦象取方位**
   例：「艮方，丑加之，故艮山」——丑临艮位，成山。
3. **方位须与事合**
   例：「北方主黑，亥加申白而生黑」——亥（黑）加申（白），黑白相生，断「造墨」。

### 三 方位与人事相配
- 占坟：艮山、坎山、乾山（来龙与坐向）
- 占店：所在之方即经营之地
- 占行：所往之方

### 四 忌
方位不可孤立断，须有类神落于其上，方成方位之断。
（「坤申方有涧水来克」——坤申为方位，涧水为其上之神象。）

## 姓氏取法（断案实证）
### 一 由支象直取
**支象中有某字者，即取为姓。**
- 寅为「**曹**职吏人」→ 断「**曹**姓举荐」
- 巳为「炉」、子为「漕」→ 合为「**卢**」（漕炉谐音）

### 二 由官称取姓
「六曹中刑部」——曹职之官，其姓多曹。

### 三 由卦象取姓
丑临艮位 → 艮山；酉为兑 → 兑少女。
（姓之取法同理：某支某卦所主之字，即为其姓。）

### 四 实证
| 课 | 支象 | 断 | 验 |
|---|---|---|---|
| 徐学士前程 | 寅为曹职吏人 | **曹姓**举荐，终六曹刑部 | 果遇曹姓人显身 |
| 赵知县在任 | 子为漕、巳为炉 | **卢**运使解纷 | 后得卢姓人解任 |

### 五 戒
**姓不可强凑。** 须支象中本有其字（曹、卢之类），方可断；
无其字而强取谐音者，多为附会。

## 处所取法（据 75 条处所析语）
### 一 支象即处所
| 支 | 处所 | 例 |
|---|---|---|
| 卯 | 门、门户、前门 | 「卯为门」「丑土加卯门之上发用，故主土塞东门」 |
| 酉 | 内门、后门 | 「酉为内门」 |
| 亥 | 厕、后阁 | 「亥为厕」「亥加丑上，故养猪（猪圈）」 |
| 巳 | 灶、厨 | 「巳为灶」「巳为炉」 |
| 未 | 庭院、后阁 | 「未为庭院」 |
| 辰戌 | 库、仓 | 「库中有鬼贼」 |
| 丑 | 田园、橱柜 | 「丑为田园」 |
| 寅 | 山林、庙 | 「寅为山林」 |

### 二 「某支加某支」定处所之方位
「丑土加**卯门**之上发用，故主**土塞东门**」——丑（土）加卯（门），土塞门。
「亥加**丑**上，故**养猪**」——亥（猪）加丑（圈）。

### 三 处所与物相配
- 门＋土 → 门被土塞
- 灶＋婢 → 婢死于厨下
- 厕＋婢 → 婢死于厕
- 阁＋猪 → 后阁为猪圈

**断处所，须「处所之支」＋「其上之物」二者合成，方为具体。**

### 四 一物多处的分辨
「婢死于**酒房厨下**」（非厕）与「婢殒命于**厕**」是两案。
**同是婢死，处所不同，全看类神临于何支**：
- 临巳（灶）→ 厨下
- 临亥（厕）→ 厕
- 临酉（酒）→ 酒房

## 数量取法（据 76 条数量析语）

### 一 数即事数
数不是抽象的，直接就是「几人、几年、几处、几所」。
| 原句 | 取法 |
|---|---|
| 「三所店，先开**二所**见财，后开**一所**主败」 | 支数＝店数 |
| 「**十人**，共**四十余口**」 | 家族人数 |
| 「**二子**死」「一子死，一子又来」 | 子息数 |
| 「**六年**之前，四分五裂」「**四年**拆屋，**六年**败尽」 | 年数 |
| 「**二十六年**寿」「**六十三**岁」 | 寿数 |

### 二 数的来源
1. **支之本数**：子午九、丑未八、寅申七、卯酉六、辰戌五、巳亥四
2. **重见倍之**：四个亥＝十六
3. **两数相合**：亥四未八＝三十二；子九申七＝六十三
4. **折半**：休囚死则减半
5. **增半**：酉六增半为九

### 三 数的校验
「**六十二岁**，盖**未交生日**故也」——**断年龄须查交生日否**，差一岁常在此。
「六月朔，因**未交小暑**，故言**五月**也」——**断月须查节气交界**。

**此二条最易错，且最易被验出来。**

### 四 戒
数须从事出。先有事，后取数；不可先算数再凑事。

## 闭口与天空之辨（重要）
两者皆主「有而不通」，但性质不同：

| 象 | 性质 | 断法 |
|---|---|---|
| **乘天空** | 有而不实 | 空口许诺、虚置、落空 |
| **闭口之支** | 有而不吐 | 收得到而不回、门不开、不愿说 |

**闭口待冲开，天空待填实。**

### 实证（失物、官讼、艺术馆三案）
- 支上见闭口 → **门不开、对方不纳**
- 中传贵人闭口 → **对方拒绝**
- 发用闭口而陷空 → **闭门不出**

### 顺序之辨
**「先有X，后得Y」** 是断顺序类问题的一条路：
若课中见「闭口」而另有「开门」之支，当先开其门，后得其应。
例：末传巳（开）克中传申（闭）→ 先通而后达。

## 支象补：申为高处
**寅临申，断「高处」**（实测：沉香案，断二楼，验）。

申本为坤、为地、为传送、为道路；然**临申取「高处」**，与「坤为高阜」之义合。
- 占失物见寅临申 → 物在高处（楼上、柜顶、架上层）
- 配合白虎（金属柜、抽屉）→ 高处的柜屉

**出处**：课主自占沉香案，三传寅申寅，寅临申，断二楼，验。

# 灵活取象与组合取象（法）

## 一 灵活取象：同一支，因所临之位而变义
**支义不是固定的，要随「它落在何处」而转。**

| 支 | 常义 | 临某位后转义 | 出处 |
|---|---|---|---|
| 申 | 道路、传送、金铁、坤地 | **临申取「高处」**（坤为高阜）→ 楼上、柜顶、架上层 | 沉香案，断二楼，验 |
| 寅 | 木器、庙、道路 | 临申 → 高处的木器 | 同上 |
| 酉 | 婢、酒、血 | 临亥 → 厕（酉加亥＝婢死于厕） | 断案 |
| 巳 | 炉灶、店业 | 临酉 → 灶下灰中 | 失金环案 |
| 辰 | 堤岸、坟、狱 | 临亥 → 水边堤岸 | 失踪案 |

**取法**：先取本义，再看所临之位能否给它一个更具体的落点。**能落则落，不能落则守本义。**

## 二 组合取象：两支相合，成一物一事
**单支只给材料，两支相合才成器物。**

| 组合 | 合成 | 出处 |
|---|---|---|
| 寅＋申 | 高处的木器（二楼木柜） | 沉香案 |
| 巳＋酉 | 炉灶灰中 | 失金环案 |
| 辰＋亥 | 水边堤岸 | 失踪案 |
| 巳＋亥 | 灶厕不便 | 占宅案 |
| 子＋亥 | 「孙」字 | 占宅案 |
| 寅＋卯 | 木器、门户、舟车 | 通用 |
| 申＋酉 | 金铁、刀、针刃 | 通用 |
| 午＋未 | 衣物、酒食、庭院 | 通用 |

**取法**：三传两两成对时，先查器物表；不成对时，取「类神所临之地盘支」与其所乘之将组合。

## 三 三层取象的次序
1. **本义**（支本身是什么）
2. **临位**（它落在哪，能否转义）
3. **合成**（与另一支／另一将合起来成什么）

**例（沉香案）**：
- 本义：寅＝木器、财
- 临位：寅临申 → **高处**（二楼）
- 合成：寅（木器）＋申（高处、金属柜）＋白虎（抽屉、破损处）→ **二楼木柜／铁柜的抽屉**

**三层缺一，就断不出「二楼电脑桌抽屉」这么具体。**

## 取象补：类神作天盘神，看其所临之地
**类神有两重位置，须并看：**

| 重 | 取法 | 主 |
|---|---|---|
| **一** 类神在地盘某支，**其上神**为何 | `tp[类神支]` | 该物「现在何处」、被什么压着 |
| **二** 类神**作为天盘神**，落在哪个地盘 | 反查 `tp[x]==类神` 的 x | 该物「往哪里去了」 |

**实证（壬午日丑将卯时，占失马）**：
- 马＝午（日支）
- 其一：地盘午，上神辰（螣蛇）→ 马在厩中受惊
- 其二：**天盘午，落在地盘申** → 「**午为马加申道路之上，正行也，被人骑去矣**」
- 案验：**马不见，被人骑走**

**书上原句只取第二重**——因为问「马哪去了」，故看它「往哪走」，不看它「原来在哪」。

**通则**：
- 问「物在何处」→ 取第一重（其上神）
- 问「物往哪去」→ 取第二重（所临之地）
- **两重俱看，方知去踪**
