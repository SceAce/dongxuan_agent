# 六壬取象二十科（据《壬之取象二十科》）

> **这二十科是「生象之法」，不是象表。**
> 象由法生，法明则象无穷；象由表查，表尽则象有穷。

## 一 五行（体用德情形色味）
| 目 | 法 | 例 |
|---|---|---|
| **体** | 五行之实体 | 水＝亥子江河；木＝寅卯林木；金＝申酉金钱；土＝四季田野。**火无体故无专象** |
| **用** | 功能 | 火：巳灶、巳烛、午晴（凶为燔烧）；水：子漕、亥子雨流（凶为漂溺）；木：卯舟车、寅梁栋；金：酉镜鼎币（凶为斩杀）；土：辰砖、丑壁（凶为狱墓） |
| **德** | 品性 | 木德疏（通敏）；土德重厚；水德柔（和顺、下冷）；火德明（上熟燥）；金德刚（果断、坚） |
| **情** | 性情 | 水贪狼、火廉贞、木阴贼、金宽大、土上奸邪下公正 |
| **形** | 形状 | 水坎曲、火中虚锐、金圆而薄、土方厚、木长直 |
| **色** | 颜色 | 火赤、金白、土黄、木青、水黑 |
| **味** | 味道 | 木酸、火苦、金辛、水咸、土甘 |

**法要**：**一个五行，可从七个角度取象。** 问形取形，问色取色，问德取德。

## 二 地支（阴阳、昼夜、奇偶）
- **自卯至申为昼，自酉至寅为夜** → 取诸昼夜
- **寅为鬼门，申为人门**
- **酉亥子并为阴私**
- **子寅辰午申戌为阳，丑卯巳未酉亥为阴**
- **阳生阴死，阳新阴旧** → 取诸奇偶
- 亥为阴关、为管、为狱、为溺；巳为钥

## 三 天象（三垣、列宿、群星、北斗、七政、云汉）
- **三垣**：子紫微宫、亥玄穹宫、丑明堂、卯天市、巳午太微
- **列宿**：房卯为轩车、箕寅为风门、南斗丑为斗、牛为关梁、室亥为楼台廪壁、奎戌为画绘、昴酉为边郡、毕申为田猎边城、参申为杀伐市贾、井未为井、鬼为鬼、七星午为性急星、翼巳为乐府飞鸟、轸为丧车
- **群星**：哭泣子、河鼓丑为将军、摄提辰为右目、天厨未为饮食、华盖子为高盖、狼狐申为劫攻、人星子为浴盆
- **北斗**：**天罡（辰）为网罗、冲破、标指、刑杀四义**
- **七政**：卯酉为门（日月五星所出）；卯六合、酉太阴取日月；戌为德合；午为荧惑
- **云汉**：寅天梁、丑桥梁、卯江河

## 四 地象（天地人身宅舍，一物一太极）
- **亥为天门、巳为地户、辰为海、亥为天柱、酉为九江、戌为天涯、辰为海角**
- **人身**：亥为头、巳为面
- **宅舍**：子为房、午为堂、丑为室阁、亥为楼台、巳为店、辰为水窗低处、戌为垒土高处

**法要**：**同一个支，取诸天、取诸地、取诸身、取诸宅，各不同。问什么就从什么角度取。**

## 五 八卦（先天／后天）
**后天**：亥乾为天为头；酉兑为泽、为少女、为妾；午离为兵、为目、为心、为中虚器（箱笼柜）、为电；巳巽为风、为店（利市三倍）；卯震为雷、为长子、为竹；寅艮为山岳；子坎为耳、为沟渎、为隐伏、为盗；丑艮为小石
**先天**：丑坤为母、为腹、为产；巳兑为口、为赏赐、为骂詈；酉坎为血；戌艮为阍寺

## 六 禽（十二属、二十八宿、三十六隐禽）
- 本属十二 → 列宿二十八 → 隐禽三十六

## 七 字（义、音、形）
| 目 | 法 | 例 |
|---|---|---|
| **义** | 取字义 | 亥为孙、子为子、卯为门、未为味、酉为酒（八月尝酌）；六合为媒人、天空为晴为声、太常为父母、勾陈为勾连 |
| **音** | 取谐音 | 巳为嗣、申为身、辰为娠又为蜃、丑为丑 |
| **形** | 取字形 | 巳为弓、申为针为箭为刺；天空为帽裹头、辛为针、丁为独脚 |

## 八 神名（十二神将本名）
**神各有名，名以德命，故可因名取义：**
- 申名**传送** → 道路
- 寅名**功曹** → 吏人、六曹
- 卯名**太冲** → 行往
- 戌名**天魁** → 集众（魁，众也）
- 辰名**天罡** → 冈狱、恶人
- 酉名**从魁** → 亚魁

**法要**：**神名即其德，名中已含象。** 传送＝道路，功曹＝吏，太冲＝行。

## 九 宫名（十二宫名）
- 巳曰**双女**、亥曰**双鱼** → 巳亥为双，主有二事
- 戌曰**白羊** → 戌为雪

## 十 藏干（杂干、寄干）
- **寅为火炬**（藏丙）；**申曰河池**（藏壬）；**未为争讼、戌为印绶**（藏丁）；**丑为水田、辰为陂池**（藏癸）
- **巳未俱为两姓**（巳寄丙戊、未寄丁己，俱藏二字）

**法要**：**支中所藏之干，即其暗中之象。** 寅藏丙故为火炬，申藏壬故为河池。

## 十一 天将（将各有家）
| 将 | 取 |
|---|---|
| 玄武 | 亥为**溺死** |
| 天空 | 戌为奴、为吏 |
| 白虎 | 申为**丧** |
| 太常 | 未为礼仪、长上、衣服 |
| 朱雀 | 午为**通语** |
| 螣蛇 | 巳为**非横灾** |
| 勾陈 | 辰为**争斗** |
| 六合 | 卯为兄弟、妇人、**女色** |
| 贵人 | 丑为贵人 |

**法要**：**将有其本家之支。** 玄武之家在亥，故亥主溺；白虎之家在申，故申主丧。

## 十二 合取（合二物成一物）★最要紧
**合二物之义以成一物：**
- 亥为高处 ＋ 营室 → **楼台**
- 亥为稻室 ＋ 盖藏 → **廪**
- 午为蚕 ＋ 妇人 → **蚕姑**
- 朱雀口舌 ＋ 午为阴阳相遇 → **通语**
- 午为屋 ＋ 路 → **巷**
- 翼为客 ＋ 轸为丧 → **吊客**
- 丑为牛 ＋ 田 → **犁**
- 寅为木 ＋ 鬼门 → **祭器、神树**

**「可类推也」——此法是生成式的，不是列举式的。**

## 十三 邻取（同方、界相集）★
**同方**：
- 亥子丑皆北 → 紫宫在北，**并为三堂**
- 巳午未皆南 → 巳午为妇人，**未亦为眷属**
- 申酉戌皆西 → 申酉为刀，**戌亦为剑锋**

**界相集**（相邻而沾其义）：
- 戌亥俱高（天门在戌亥间）
- 辰巳俱低（地户在辰巳间）
- 亥为楼、**戌为阁**（阁道绝汉抵营室）
- 酉为边郡、**申为边城**（天街在申酉间）
- 丑子相邻 → 子房，**丑亦为室**
- 亥子相邻 → 子悲，**亥亦为哀**
- 子为阴藏 → **亥为阴囊**
- 戌亥相邻 → 亥溷厕，**戌为浴室**
- 寅卯相邻 → 卯舟，**寅为橹**

**法要**：**象会「传染」给邻居。** 甲有此象，其邻支可沾得。

## 十四 对取（从、反）★
**相反（相对而立）**：
- 亥为管 ↔ **巳为钥**
- 亥为头 ↔ **巳为面**
- 亥为天头 ↔ **巳为地足**
- 卯为前门 ↔ **酉为后门**

**相从（同类而并）**：
- 辰为网 ↔ **戌为罗**
- 酉为刀 ↔ **卯为砧**
- 午为使君 ↔ **子为监司**
- 午为堂 ↔ **子为房**
- 寅为道 ↔ **申为僧**
- 寅为神 ↔ **申为佛**
- 辰戌并为恶人、为奴仆、为军徒、为欺诈、为锹镬

**法要**：**知道一边，可推其对边。** 这是最省力的一法。

## 十五 三合（异方各相类从）
- 申为湖塘、子为江漕、辰为池缸 → **皆水之属**
- 巳酉为解散、丑为冤 → **皆离革之象**
- 寅午为信诚、戌为德合 → **皆火之情**
- 亥卯为阴贼、未为奸邪 → **皆木之情**

**法要**：**三合之支，其象同类相从。**

## 十六 四方（孟仲季）
- **孟**（寅申巳亥）：长生之首 → 寅为道士；**皆为圆、为活、为已过**
- **仲**（子午卯酉）：沐浴之首 → 子为浴盆；**皆为方、为塑画、为当时**
- **季**（辰戌丑未）：**皆为狱、为墓、为老人、为暮年**；**皆为尖碎、为死、为未来**
- 四仲为关格

## 十七 借取（借邻、谐音拆字）
**借邻**（借傍宫之星）：
- 天谗主医，星在酉，而**申为医**
- 七星主衣裳文绣，星在午，而**未为衣服**
- 柳在午，而**未为争讼**
- 巽为风，先天在申，而**未为风师**
- 震为龙，龙司雨，而**丑为雨师**

**谐音拆字**：
- 卯为私门 → 借为**沙门**
- 巳中有翼宿 → 借翼头彐为**雪**
- 卯为轳 → 借为**驴**

## 十八 推取（同类、别类）★
**推之同类**：
- 辰为鱼 → 推之水族、海味、盐
- 巳为蚓 → 推之虫
- 午为鹿 → 推之麋
- 申为猿 → 推之獲
- 酉为鸡 → 推之鸭
- 未为雁 → 推之鸠鸽鹊
- 午为马 → 推之蚕（蚕马同类）
- 丑为牛 → 推之犀
- 酉为酒 → 推之醋酢酱
- 申为医 → 推之药
- 巳为灶 → 推之锅
- 卯为门 → 推之窗牖、床、帐
- 未为眷属 → 推之姑娣妹
- 丑为僧 → 推之尼

**跨界推**：
- 器物推人：巳灶→庖人；寅庙→祝子；江湖→渔人；未酒筵→乐官；午马→兽医、御马人；丑牛→牧人
- 人物推屋室：戌军→营寨；申僧→寺院；戌犬→犬巢；亥猪→猪栏
- 器物相推：巳弩→穿甲；卯兔→格兔；申麦→磨；卯车→驴骡
- 物推人形：辰龙→身绣龙文；酉鸡→雀子斑；未羊→羊目
- 人事推鬼神：子岁官→上帝；阴私→淫祀；寅为稷神

**法要**：**取到一象，可推其同类、其别类、其反面（如器物推人）。** 这是象的繁殖法。

## 十九 转取（意相禅代）★
**类不相蒙，意相禅代**：
- 未本为服 → 转孝服 → 转白头 → 转**雪**
- 酉为降、门内、宽大 → 因水降转**恩泽** → 因恩泽转**赏赐**
- 寅为虎 → 虎有斑 → 转**斑点** → 转**杂色**
- 古有「稼穑艰难」之语 → 课得稼穑 → 转**艰难**

**法要**：**象可层层转义。** A→B→C，只要每一步有由。

## 二十 造字（偏旁、全字）
**偏旁**：
- 子为点水、耳旁、女旁、衣旁；丑土旁；寅木旁、宀头、佳字
- 卯草头、丝旁、阝、乙旁；辰山旁、土旁、厂旁
- 巳火、巳字、弓旁；午火旁、者字；申金旁、立人、走脚（申为道路）、刀旁
- 酉口旁、双立人；戌犬旁、戈旁

**全字**：
- 巳为辘轳之转；未为杨羊之转；子为沉（坎为穴）；卯为陈（东门）
- 亥为殳（乾为殳）；秋金为菊

**配字**：
- **巳酉相为配字**；**丑未相加为魁字**（丑中有斗、未中有鬼，利考试）
- **邵公以酉亥丑相并为「润」字**
- **亥子丑相连为「法」字**（水顺去也）
- 六月朱雀加酉为「酱」字
- 己日戌并午未为「粽」字

## 总结：二十科的用法

| 类 | 科 | 作用 |
|---|---|---|
| **本** | 一五行、二地支 | 定基本性质 |
| **天地** | 三象、四象、五卦 | 定所在之界 |
| **名** | 六禽、七字、八神名、九宫名、十藏干 | **因名取义** |
| **将** | 十一 | 将有其家 |
| **合** | **十二合取、十三邻取、十四对取、十五三合** | **象的生成** |
| **推** | **十七借取、十八推取、十九转取、二十造字** | **象的繁殖** |
| **位** | 十六四方 | 孟仲季定死活 |

**最要紧的是十二至二十这九科**——它们让象可以**从无到有、从一个到无穷**。

前面十一科是「有什么」，后面九科是「怎么生」。
