# 九宗门定法（据景祐卷三·释用式、指南卷一、类集）

## 总次序（不可颠倒）
1. **先看四课有无下贼上**（下克上），有则取。
2. **无下贼上，看有无上克下**，有则取。
3. 多处克贼 → **比用**（与日干阴阳比者）。
4. 比复等 → **涉害**（取四孟，再比深浅）。
5. 四课全无克 → **遥克**（先神遥克日，无则日遥克神）。
6. 无遥克 → **昴星**。
7. 阴阳不备而无可取 → **别责**。
8. 干支同位（两课）→ **八专**。
9. 天地盘重叠或对冲 → **伏吟／返吟**。

## 各门细则

### 一 贼克
- 下贼上优先于上克下。即使上克下多而下贼上只一处，**仍取下贼上**（景祐：若三上克下、一克上，当以一下克上为用）。
- 一处下贼上＝重审；一处上克下＝元首。

### 二 比用（知一）
- 多处克贼，取与日干**阴阳相比**者（甲丙戊庚壬取阳支，乙丁己辛癸取阴支）。
- 俱比或俱不比，进入涉害。

### 三 涉害（见机／察微）
- **先取所临地盘为四孟（寅申巳亥）者** —— 用孟曰见机。
- 复等 → 比涉害深浅：**自所临地盘顺行回本家，数所历克贼，取最深**。
- 再等 → **刚日取日上神，柔日取辰上神**（刚用日比，柔用辰比）。
- 用孟者名见机，用仲季者名察微。

### 四 遥克
- 先取**神遥克日**（蒿矢）；无则取**日遥克神**（弹射）。
- 日克两神或两神克日 → 仍取比者。
- 蒿矢主外来之祸，弹射主自取之祸，皆力薄「无所中」。

### 五 昴星
- 刚日：**仰视酉上所得之神**为初传；中传取支上神，末传取日上神。
- 柔日：**俯视从魁所临之辰**（即天盘酉下之地盘支）为初传；中传取日上神，末传取支上神。
- 主伏藏、静守，刚日动而滞，柔日伏而不见。

### 六 别责
- 四课不备（只有三课）且无克无遥。
- **刚日取干合上神**为初传，中末俱取日上神。
- **柔日取支合上神**为初传，中末俱取日上神。
- 主有待、事不专。

### 七 八专
- 干支同位，只有两课。
- 有克 → 仍用比用涉害。
- 无克 → **刚日从日上神顺数三辰**为初传；**柔日从辰上神逆数三辰**为初传；中末取日上、辰上（一云末传与初传同）。
- 主不正、帷簿不修。

### 八 伏吟
- 天地盘重叠。
- 有克 → 以克处为初传；次传其辰，末传取所冲（六乙日）；或尽刑为三传（六癸日）。
- 无克 → 刚日取日上神、柔日取辰上神为初传，**尽三刑为中末传**。
- 遇自刑：刚日先日次辰、辰所刑为末；柔日先辰次日、日所刑为末。次传自刑则取冲为末。

### 九 返吟
- 天地盘对冲。
- 多相克 → 以克处为初传，**先冲后刑**为三传；无刑则用冲。
- 无克（丁丑己丑辛丑丁未己未辛未）→ **以辰冲为用**：丑日冲巳，取天盘巳上神为初传；未日冲亥，取天盘亥上神为初传；次传辰上，末传日上。

## 八专取传（已通）
景祐原文：「若无克者，刚日从日上阳神顺数三辰为用，柔日从辰上阴神逆数三辰为用，
中传、末传当以日辰上神重之。」
三处易错：
1. 数三辰自**神本身**起（含本次为第一），非自所临地盘起。
2. 柔日取**辰上阴神＝第四课**，非第三课。
3. 中传取日上神、末传取辰上神（「以日辰上神重之」），非顺推连生。
验证：庚申日卯将寅时 → 亥酉酉；己未日丑将亥时 → 酉酉酉。两例与书全合。
