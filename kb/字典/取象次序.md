# 取象次序（据三案断语实测）

> 邵彦和断语的次序是固定的：**从大到小，从外到内，最后到生死。**
> 不是随手说的，是有先后。

## 一 六步次序

```
① 定调     此课什么势（一句）
② 宅      宅如何（支、支上、宅之象）
③ 人口    家中人如何（本命、行年、六亲、子孙、婢妾）
④ 处所    具体某处（门、堂、阁、厕、灶、树、坟）
⑤ 财      财如何（财爻、财库、经营）
⑥ 结果    几年、几时、死生
```

## 二 三案实证

| 次序 | 王德卿案 | 张九翁案 | 童保仪案 |
|---|---|---|---|
| ① 定调 | 财禄极稳，但自有膀胱气之扰 | 利宅不利人 | 六阴相继，衰败不振 |
| ② 宅 | 宅上帝旺，财物兴隆 | 宅上亥为脱神 | 宅前大树枯朽 |
| ③ 人口 | 今年进子又添孙 | 为儿娶妇、阴人守寡 | 婢殒命于厕、一子患腹气 |
| ④ 处所 | 堂上不合安符 | 动店内物 | 后阁为猪圈 |
| ⑤ 财 | 池塘之利大发 | 费用尽坏家计 | 四年拆屋卖 |
| ⑥ 结果 | 二十六年寿，水肿亡 | 十一年家产四分 | 四年败，六年败尽 |

## 三 各步看什么

| 步 | 看哪 | 取什么象 |
|---|---|---|
| **① 定调** | 格名、最反常处 | 六阴、赘婿、乱首、无禄、极阴 |
| **② 宅** | 支、支上神 | 支上神空＝宅基未定；支为日墓＝宅有旧冢；支受克＝宅败 |
| **③ 人口** | 本命、行年、六亲 | 六亲定谁；酉为婢；亥为妇人；太阴为老阴人 |
| **④ 处所** | 门、堂、阁、厕、灶、树、坟 | 卯门、午堂、亥厕、巳灶、丑阁、辰坟 |
| **⑤ 财** | 财爻、财库、青龙 | 财空、财库破、财入墓 |
| **⑥ 结果** | 末传、数法、死地 | 末传入墓＝止；数法定年；死地定死 |

## 四 次序为什么重要

**王德卿案，若先看「膀胱气」，就变成断病；先看「财禄极稳」，才是断宅。**

**邵彦和先给「财禄极稳，但自有某病」——一句话把主次定了。**

**次序错，主次就错。**

## 五 问事不同，次序略变

| 所问 | 次序 |
|---|---|
| **占宅** | 定调→宅→人口→处所→财→结果 |
| **占病** | 定调→病在何部（日上／支上）→病源→轻重→死期→办法 |
| **占讼** | 定调→谁占理→胜负→何时断→后果 |
| **求财** | 定调→财在哪→得不得→几时→办法 |
| **占婚** | 定调→谁为主→成不成→何时→后事 |
| **失物** | 定调→类神在不在传→在哪→谁动→几时 |

**次序随事类变，但都是「先定调，后由大到小」。**
