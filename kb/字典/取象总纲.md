# 取象总纲（把三本书合成一条路）

> 象不是查来的，是**生出来的**。
> 《二十科》给生法，《五行大义》给本源，《断案》给实证。

## 一 象从哪来：四个源头
| 源 | 出什么 | 例 |
|---|---|---|
| **名义** | 干支名字本身就是象 | 子＝孳、酉＝老熟、戌＝灭、亥＝核；甲＝押、丙＝炳、庚＝更 |
| **体性** | 五行的体与性 | 木温柔曲直（内虚）、火炎上（内暗）、金从革（杀性在外）、水润下（内明） |
| **位势** | 落在哪、旺不旺 | 寅落申＝高处；午落戌＝灯在库中；金在午＝死 |
| **生成** | 用二十科之法推 | 见下 |

## 二 生象九法（二十科中能"生"的九科）
| 法 | 怎么生 | 例 |
|---|---|---|
| **合取** | 二物义合成一物 | 亥（高处）＋营室＝楼台；午（屋）＋路＝巷；丑（牛）＋田＝犁 |
| **邻取** | 象传染给邻支 | 卯舟→寅橹；子房→丑室；亥厕→戌浴室；酉边郡→申边城 |
| **对取** | 知一边推对边 | 亥管→巳钥；卯前门→酉后门；酉刀→卯砧；午堂→子房 |
| **三合** | 三合之支象同类 | 申湖塘、子江漕、辰池缸（皆水属） |
| **借取** | 借傍宫星、谐音拆字 | 天谗在酉→申为医；卯私门→借沙门；巳翼宿→借彐为雪 |
| **推取** | 同类推、别类推、跨界推 | 巳灶→锅→庖人；申医→药；卯门→窗床帐；酉酒→醋酱 |
| **转取** | 意相禅代，层层转 | 未服→孝服→白头→雪；酉降→恩泽→赏赐；寅虎→斑→杂色 |
| **造字** | 偏旁、全字 | 子点水耳旁女旁；寅木旁宀头；丑未相加＝魁；酉亥丑＝润 |
| **藏干** | 支中所藏之干即暗象 | 寅藏丙故火炬；申藏壬故河池；未藏丁故争讼；辰藏癸故陂池 |

## 三 取象的次序（一条可执行的路）
```
一 抓主象      什么最反常（几见／俱下贼／全空／上下俱脱）
二 定名义      此支此干，名中何义（子孳、酉老、戌灭）
三 看体性      其五行之体性（木内虚、金杀外、水内明）
四 看位势      落在哪（转义）＋旺衰（长生十二位）
五 生成        用九法推（合／邻／对／三合／借／推／转／造字／藏干）
六 成画面      带动作的一句话（土塞东门、灯在库中、婢死于厕）
```

## 四 取象的分寸（三条）
1. **象须落物**：树、门、灯、灶、厕、柜、堤、犁、磨——不是抽象词
2. **象须可串**：单象不成事，须与六亲／长生／将串成链
3. **象不逆理**：五行说是克，象不能取成生；位势说是死，象不能取成旺

## 五 二十科的用法次序
| 顺序 | 科 | 何时用 |
|---|---|---|
| 先 | 一五行、二地支 | 定性质 |
| 次 | 八神名、十藏干 | **因名取义（最省力）** |
| 次 | 十二合取、十三邻取、十四对取、十五三合 | **象不够时生象** |
| 再 | 十七借取、十八推取、十九转取、二十造字 | **象太死时转活** |
| 末 | 十六四方（孟仲季） | 定死活、定已过/当时/未来 |

## 六 一条实证（叶七秀才案，逐句对应）
| 原句 | 用的哪一法 |
|---|---|
| 丑土生辛金，故为母 | 五行＋六亲 |
| 寅艮方，丑加之，故艮山坟地 | 位势（寅在艮）＋合取 |
| 金绝于寅，故主妻死 | 十二长生＋六亲 |
| 传见子亥，金水相生，退脱 | 五行相生 |
| 亥为肾 | 名义／直取 |
| 玄武主疝气 | 将之本病 |
| 金死于子 | 十二长生 |
| 亥四子九，十三年 | 数法 |
| 水便陡泻，自西北上出去 | 位势（子亥逆入西北） |
