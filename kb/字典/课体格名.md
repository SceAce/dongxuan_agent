# 课体格名（据《大六壬指南》课体歌诀）

> **格名是钥匙。** 一取格名，整课性质即定，后续推断自然而出。
> 邵彦和定调必先说格名：「名曰赘婿」「此课六阴相继」「贵人失位」。

|---|---|---|

## 五 六阴（重要的定调格）
> 「大凡丑亥酉卯此四支，先生皆以**极阴**。」
> 「此课**六阴相继，更无阳神**……命从此衰败不振。」

**取法**：三传与四课上神尽为丑亥酉卯，或课传纯阴。
**断**：**阴长阳消，极矣；主衰败、昏晦、阴私**。喜空亡可解。

## 六 断吉凶从将意
> 「凡断吉凶，**占从将意**。」

**即：格名定性质，天将定具体事。**

## 八 用法：定调先取格名
```
一 看九宗门 → 得基本格（元首／知一／涉害／遥克／昴星／别责／伏吟／返吟／八专）
二 看三传成局 → 稼穑／曲直／从革／炎上／润下
三 看特殊格 → 赘婿／乱首／无禄／绝嗣／龙战／芜淫／三交／斩交／游子／天狱／天网
四 取格名 → 一句话定调
```

**例**：
- 支加干被克 → **赘婿** → 「屈身于人，不能自立」→ 无正居 → 屋不存立
- 六阴相继 → **极阴** → 「阴长阳消」→ 衰败不振
- 四上克下 → **无禄** → 「上骄下弱，无禄犹无路」

**格名一定，后面的推断是顺着格名推出来的，不是另找象。**
